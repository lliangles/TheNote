## 🚀 筆記查閱與同步指南

1. **進入總覽看板**：打開 [[dashboard/progress.md]] 即可查看全學期所有科目的進度矩陣與單元入口。
2. **平板端同步**：在電腦端終端機執行 `git push origin main`，隨後即可在平板端透過 Obsidian Git 外掛一鍵 Pull 同步。
3. **課堂筆記增修**：每篇筆記底部均附有 `[!note] 課堂速記` 留白區，方便上課時隨堂增補關鍵重點。
