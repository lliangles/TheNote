## 🚀 黃金空堂與深度工作區塊（Deep Work Blocks）

資管系大二課業繁重（資料結構、資料庫、統計學三座大山 + AI、網路管理、金融市場），善用大塊空堂是致勝關鍵：

### 1. 🌟 週三下午黃金區塊（12:20 ~ 21:30 全空！）
* **定位**：每週最核心的「連續沉浸工作日」。
* **規劃建議**：
  * `12:20 ~ 13:00`：午餐與午休沉澱
  * `13:00 ~ 16:30`（第一輪讀書 3.5hr）：**【重型實作】資料結構程式碼實作 / AI Python 演算法專題**

  * `17:30 ~ 18:00`：沐浴洗漱（30m）
  * `18:00 ~ 18:20`：晚餐（20m）
  * `18:30 ~ 21:30`（第二輪讀書 3hr）：**【作業與理論】資料庫 SQL / 統計學作業 / 筆記整理**

### 2. 🌟 週五下午收斂區塊（15:00 ~ 21:30）
* **定位**：全週筆記結算與週末前減壓。
* **規劃建議**：
  * 把一週的各科筆記確認連結與截圖無誤。
  * 清除本週即將截止的 DDL 作業。
  * 傍晚跑操場 1 小時，迎接清爽週末。

### 3. 🌟 週三、週四早晨微空堂（08:00 ~ 10:00）

* **規劃建議**：進行需要高度清醒的高難度概念預習（如：統計學機率公式、CCNA 路由運算）。

## 🏃 「讀書 ➔ 跑步 ➔ 滿血讀書」神級循環模型

研究顯示，高強度認知工作 2~3 小時後大腦認知資源會枯竭。插入 1 小時操場有氧慢跑能刺激 BDNF（腦源性神經營養因子），大幅提升後續記憶固化率：

```
[ 深度讀書 / 寫 Code 2.5 ~ 3 小時 ]
         │
         ▼  (大腦微疲勞、注意力開始發散)
[ 🏃 操場慢跑 60 分鐘 ]  ← 徹底放空、聽節奏音樂或反芻難點
         │
         ▼
[ 🚿 沐浴洗漱 30 分鐘 ]  ← 降溫、冷卻神經系統
         │
         ▼  (生理喚醒度重置，重返專注高峰)
[ 深度讀書 / 整理筆記 2 ~ 2.5 小時 ]
         │
         ▼
[ 22:00 每日 Git 同步與復盤 (30m) ]
         │
         ▼
[ 22:30 準時熄燈就寢（睡滿 8 小時）]
```
