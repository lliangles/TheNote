## 1. 全科目核心統計公式極速備忘錄

### 1.1 離散趨勢與常態分佈
- 樣本變異數：$s^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1}$
- 常態標準化：$z = \frac{x - \mu}{\sigma}$

### 1.2 抽樣分配與中央極限定理 (CLT)
- 樣本平均數期望值與標準誤：$E(\bar{x}) = \mu, \quad \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$
- 有限母體校正因子 (FPC)：若 $n/N > 0.05$，需乘上 $\sqrt{\frac{N - n}{N - 1}}$

### 1.3 區間估計 (Confidence Intervals)
- $\sigma$ 已知：$\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$
- $\sigma$ 未知：$\bar{x} \pm t_{\alpha/2} \frac{s}{\sqrt{n}}$ (自由度 $df = n - 1$)
- 母體比例：$\bar{p} \pm z_{\alpha/2} \sqrt{\frac{\bar{p}(1 - \bar{p})}{n}}$
- 樣本數規劃：$n = \frac{(z_{\alpha/2})^2 \sigma^2}{E^2}$

### 1.4 假設檢定 (Hypothesis Testing)
- 決策準則：$p\text{-value} \le \alpha \implies \text{拒絕 } H_0$
- 雙尾檢定 p 值必須乘以 2。

## 2. Excel 統計必備函數速查

| 統計需求 | Excel 公式 | 說明 |
| :--- | :--- | :--- |
| 標準常態累積機率 $P(Z \le z)$ | `=NORM.S.DIST(z, TRUE)` | 輸入 $z$，求左尾累積機率 |
| 給定機率反求臨界值 $z$ | `=NORM.S.INV(prob)` | 輸入累積機率，求 $z$ 值 |
| $t$ 分配雙尾 $p$ 值 | `=T.DIST.2T(ABS(t), df)` | 快速計算雙尾 $t$ 檢定 $p$ 值 |
| $t$ 分配雙尾臨界值 | `=T.INV.2T(alpha, df)` | 輸入 $\alpha$ 與自由度，求臨界 $t$ 值 |
| 平均值與標準差 | `=AVERAGE(範圍)`, `=STDEV.S(範圍)` | 基礎敘述統計量 |
