# 出題與答案範例（請完全複製此格式與難度出題）：

【題目範例 1】
情境：你是人事主管，手上有員工基本資料表。你想透過輸入「員工編號」，自動在隔壁欄位「查出」該員工對應的「部門名稱」。
正確答案：=VLOOKUP(查閱值, 表格陣列, 欄位編號, 精確匹配) 或 =XLOOKUP(查閱值, 查閱陣列, 回傳陣列)

【題目範例 2】
情境：你是銷售經理，手上有全台各分店的營收明細。你想計算在「台北店」且產品類別為「3C」的「銷售總金額」。
正確答案：=SUMIFS(求和範圍, 條件範圍1, 條件1, 條件範圍2, 條件2)

【題目範例 3】
情境：你是財務專員，有一張客戶請款清單。你想知道其中「尚未付款」的客戶總共有「幾家」。
正確答案：=COUNTIF(範圍, 標準)
