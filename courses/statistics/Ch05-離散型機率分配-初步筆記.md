## 1. 隨機變數期望值與變異數

設離散隨機變數 $X$ 的機率質量函數（PMF）為 $f(x) = P(X = x)$：
1. **機率性質**：$0 \le f(x) \le 1$ 且 $\sum f(x) = 1$。
2. **期望值 (Expected Value / Mean)**：
   $$E(X) = \mu = \sum x \cdot f(x)$$
3. **變異數 (Variance)**：
   $$\text{Var}(X) = \sigma^2 = \sum (x - \mu)^2 \cdot f(x) = E(X^2) - [E(X)]^2$$
4. **標準差**：$\sigma = \sqrt{\text{Var}(X)}$。

---

## 2. 二項機率分配 (Binomial Distribution)

### (1) 試驗條件（白努力試驗 Bernoulli Process）
- 試驗由 $n$ 次相同且獨立的重複試驗構成。
- 每次試驗只有兩種互斥結果：成功（機率 $p$）與失敗（機率 $1 - p$）。
- 每次試驗成功的機率 $p$ 保持固定。

### (2) 公式與特徵值
隨機變數 $X \sim B(n, p)$ 代表 $n$ 次試驗中成功的次數：
$$f(x) = C_x^n p^x (1 - p)^{n - x} = \binom{n}{x} p^x (1 - p)^{n - x}, \quad x = 0, 1, 2, \dots, n$$

- **期望值**：$E(X) = n \cdot p$
- **變異數**：$\text{Var}(X) = n \cdot p \cdot (1 - p)$
- **標準差**：$\sigma = \sqrt{n p (1 - p)}$

---

## 3. 卜瓦松機率分配 (Poisson Distribution)

### (1) 應用情境
用於衡量在**某固定時空區間**（如每小時、每天、每公里）內，特定罕見事件發生的次數（如：客服中心每小時進線電話數、高速公路每百公里車禍次數）。

### (2) 公式與特徵值
隨機變數 $X$ 代表區間內事件發生的次數，$\mu$ 或 $\lambda$ 為該區間內平均發生次數：
$$f(x) = \frac{e^{-\mu} \cdot \mu^x}{x!}, \quad x = 0, 1, 2, \dots$$

> [!IMPORTANT] 卜瓦松分配神級特性
> **期望值與變異數完全相等**：
> $$E(X) = \text{Var}(X) = \mu$$

---

## 4. 對應 Excel 函數

- 二項機率：`=BINOM.DIST(x, n, p, cumulative)`（`FALSE` 為單點機率，`TRUE` 為累積機率）。
- 卜瓦松機率：`=POISSON.DIST(x, mean, cumulative)`。
