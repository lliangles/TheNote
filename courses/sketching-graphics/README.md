# 🎨 素描與圖學 (Sketching and Graphics)

## 📌 基本資訊
- **授課教師**：楊德全
- **上課時間與教室**：週五 13:00~14:50 (節次 5, 6) @ D2-405
- **核心目標**：培養造形觀察力、圖學原理、透視法與手繪/電繪基礎表達能力。

## 📅 學習進度與成果展示
- W1~W4：造形觀察、線條練習與基本幾何體素描
- W5~W8：透視圖學原理（一點/兩點透視）、光影明暗表現
- W9：期中作業檢核
- W10~W14：材質表現、實物寫生與構圖原理
- W15~W16：綜合專題創作與作品展示
- W17~W18：彈性教學 / 總整期末作品集
