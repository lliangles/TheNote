## 📌 1. 貨幣總計數劃分架構 (Monetary Aggregates)

中央銀行依據金融資產之**流動性強弱 (Liquidity)**，將貨幣總計數劃分為三個同心圓層級：

| 層次 | 包含成分 | 經濟意涵 |
| :--- | :--- | :--- |
| **M1a** | 通貨淨額 + 支票存款 + 活期存款（主要為企業營運用） | 具備最高變現性、純交易媒介 |
| **M1b** | **M1a + 活期儲蓄存款**（主要為個人與家計單位持有） | 衡量民間即期消費能力與股市資金動能的最重要指標 |
| **M2** | **M1b + 準貨幣 (Quasi-Money)**（定期存款、定儲、外幣存款、郵局儲金等） | 廣義貨幣總量，央行主要的貨幣政策**中間目標** |

## 📌 2. 貨幣政策傳遞四部曲

中央銀行推動貨幣政策時，無法直接一步到位達成控制物價與就業的終極目標，必須經由指標層層傳遞：

$$\text{政策工具} \longrightarrow \text{操作目標 (Operating Target)} \longrightarrow \text{中間目標 (Intermediate Target)} \longrightarrow \text{最終目標 (Ultimate Goal)}$$

| 政策階段 | 核心指標與實務工具 | 央行之控制程度與反應速度 |
| :--- | :--- | :--- |
| **1. 政策工具** | **一般性工具**：法定存款準備率、重貼現率、公開市場操作 (OMO)；<br>**選擇性工具**：不動產信用管制、消費者貸款管制 | 央行擁有 100% 絕對主控權，可隨時發動 |
| **2. 操作目標** | **銀行準備金總額 (Bank Reserves)**、**金融業隔夜拆款利率 (Interbank Call Rate)** | 央行可每日透過公開市場操作密切監控與微調 |
| **3. 中間目標** | **廣義貨幣供給量 (M2 成長率)**、長短期利率水準 | 具備高度可測性、可控性，且與最終目標高度相關 |
| **4. 最終目標** | **維持物價穩定**、促進經濟健全成長、充分就業、健全銀行業務 | 政策最終追求之宏觀經濟福祉 |

## 📌 3. 央行四大政策工具深度剖析

1. **法定存款準備率 (Required Reserve Ratio)**：
   - 效力最猛烈、最具震撼性的核武級工具。調高準備率會直接降低貨幣乘數 $m$，大幅收縮整體銀行體系的信用創造能量。
2. **重貼現率 (Rediscount Rate)**：
   - 銀行持合格票券向央行融通借款之基準利率。調升重貼現率具有強烈的「宣示效果 (Announcement Effect)」，引導全體金融體系放款利率走揚。
3. **公開市場操作 (Open Market Operations, OMO)**：
   - 最具彈性、最常用之日常微調工具。央行於公開市場發行定期存單 (NCD) 或附買回賣出債券以收回游資（緊縮）；買入債券以釋放強力貨幣（寬鬆）。
4. **選擇性信用管制 (Selective Credit Controls)**：
   - 針對特定過熱部門（如不動產炒作、汽車分期付款等）進行重點打擊。

## 📌 4. 分期付款信用管制之數理機制

### 💡 經典應用例題 4-1：消費者信用管制抑制支出之最強組合
> **情境（出自期中試題第 15 題）**：  
> 若中央銀行欲透過分期付款信用之付款條件進行管制以有效抑制消費者過度支出，應採取何種條件組合？

#### 📝 解題步驟與簡答：
1. **提高頭期款最低金額/成數**：
   - 若原本買車自備款只需 10%（10 萬元），央行強制調升至 40%（40 萬元），能立即將儲蓄不足的投機型買家阻擋在市場之外。
2. **縮短償還最長期限**：
   - 若原本可分 7 年（84 期）攤還，央行強制壓縮為 2 年（24 期），每期應繳本息將暴增數倍，加重每月的現金流負擔，使消費者望而卻步。
- **【簡答】**：最佳政策組合為**「提高頭期款的最低金額以及縮短償還的最長期限」**。
