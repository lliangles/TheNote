## 1. 遠期 vs 期貨合約核心差異

| 比較項目 | 遠期合約 (Forward) | 期貨合約 (Futures) |
| :--- | :--- | :--- |
| **交易場所** | 場外櫃檯交易 (OTC) | **集中交易所 (如期交所)** |
| **合約規格** | 買賣雙方客製化 | **高度標準化** (標的、數量、到期日) |
| **信用違約風險** | 高 (承擔對手方信用風險) | **極低 (結算所 Clearinghouse 擔任保證人)** |
| **結算方式** | 到期一次交割結算 | **逐日結算 (Mark-to-Market)**，保證金制度 |

## 2. 選擇權 (Options) 四大基本部位四象限損益

```text
1. 買進買權 (Long Call): 看大漲     2. 賣出買權 (Short Call): 看不漲
   損益 = max(S_T - K, 0) - Premium     損益 = Premium - max(S_T - K, 0)
   獲利無上限，最大損失為權利金          最大獲利為權利金，損失無上限

3. 買進賣權 (Long Put): 看大跌      4. 賣出賣權 (Short Put): 看不跌
   損益 = max(K - S_T, 0) - Premium     損益 = Premium - max(K - S_T, 0)
   標的跌至0時獲利最大，損失為權利金     最大獲利為權利金，下跌損失龐大
```

## 3. 買賣權平價理論 (Put-Call Parity - 必考)
在無套利機會下，相同履約價 $K$ 與到期日 $T$ 的歐式買權與賣權滿足：
$$\mathbf{C + \frac{K}{(1 + r)^T} = P + S_0}$$
*(買進買權 + 零息無風險債券 = 買進賣權 + 現貨股票)*
