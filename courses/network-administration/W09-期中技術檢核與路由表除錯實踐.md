## 1. 核心檢查與驗證指令三劍客

在 Cisco 路由器除錯時，優先執行三大黃金指令：

```text
1. 介面狀態快速掃描：
Router# show ip interface brief
Interface                  IP-Address      OK? Method Status                Protocol
FastEthernet0/0            192.168.1.1     YES manual up                    up      
Serial0/0/0                10.1.1.1        YES manual up                    down    
(關鍵：Status 代表實體層 L1，Protocol 代表資料鏈結層 L2；必須雙 UP 才算正常運作)

2. 尋徑表路由狀態檢視：
Router# show ip route
Codes: L - local, C - connected, S - static, R - RIP, M - mobile, B - BGP
       D - EIGRP, EX - EIGRP external, O - OSPF, IA - OSPF inter area
```

## 2. 連通性測試符號解析 (Ping 輸出)

- **`!` (驚嘆號)**：成功收到 ICMP Echo Reply（連通正常）。
- **`.` (句點)**：Request timed out（請求逾時，可能是路由遺失、被 ACL 阻擋或目標離線）。
- **`U`**：Destination unreachable（目標無法到達，通常由路由器丟棄封包時回覆）。
- **`Q`**：Source quench（來源抑制，目的地過度壅塞）。
- **`&`**：TTL expired in transit（跳數超過上限，可能存在路由無窮迴圈 Routing Loop）。

## 3. 常見介面狀態除錯指南

| Status 狀態 | Protocol 狀態 | 故障根源推斷 | 排除處置 |
| :--- | :--- | :--- | :--- |
| **administratively down** | **down** | 介面處於關閉狀態（預設未開機） | 進入該介面輸入 `no shutdown` |
| **down** | **down** | 實體線路問題（線未插、斷線、網線損壞） | 檢查跳線/光纖接頭、模組是否插妥 |
| **up** | **down** | L2 資料鏈結層封裝不匹配；串列線路無時脈 | DCE 端補上 `clock rate 9600`；檢查兩端 HDLC/PPP 封裝 |
| **up** | **up** | 正常運作中 | 介面正常，可進行 L3 封包轉發 |
