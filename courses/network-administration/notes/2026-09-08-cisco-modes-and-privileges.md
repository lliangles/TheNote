以下為您整理這三個核心模式之間的切換指令、快捷鍵，以及遇到輸入錯誤卡住時的必殺解法！

## 1. 三大模式切換指令與快捷鍵

切換模式就像在不同的房間進出，有專屬的「開門」與「退回」指令：

|目前所在模式|目標模式|輸入指令 / 快捷鍵|說明|
|---|---|---|---|
|`Router>` (大廳)|→ `Router#` (主控室)|`enable` (簡寫 `en`)|升級成特權模式（通常需要輸入密碼）|
|`Router#` (主控室)|→ `Router>` (大廳)|`disable`|降低權限，退回一般模式|
|`Router#` (主控室)|→ `Router(config)#` (工程房)|`configure terminal` (簡寫 `conf t`)|進入全域設定模式|
|`Router(config)#` (工程房)|→ `Router#` (主控室)|`exit`|退回上一層（主控室）|
|`Router(config-if)#` (深層工程房)|→ `Router#` (主控室)|`end` 或 快捷鍵 `Ctrl + Z`|一鍵大跳躍：不論在多深的子模式，直接退回最外層的主控室 `#`|

## 2. 輸入錯誤卡住怎麼辦？（救命兩招）

在 Cisco 設備中，如果您不小心把指令拼錯（例如把 `show` 打成 `shwo`），系統會誤以為你想連線到一台叫做 "shwo" 的電腦，並開始嘗試進行 DNS 網域名稱解析。這時畫面會卡住，顯示類似：  
`Translating "shwo"...domain server (255.255.255.255)`

這時候鍵盤怎麼敲都沒反應，請用以下方法解決：

## 🔴 第一招：當下卡住的強制中斷快捷鍵（最常用）

- 同時按下：`Ctrl` + `Shift` + `6`
- 說明：這是 Cisco 系統的強制中斷鍵（也常寫作 `Ctrl + ^`）。按下後可以立即中斷 DNS 查詢，還你正常的輸入游標。在某些模擬器（如 Packet Tracer）中，有時需要多按一兩次。

## 🟢 第二招：一勞永逸法（直接關閉這個煩人的功能）

為了避免以後每次打錯字都要等或手忙腳亂按快捷鍵，建議一進到設定模式，就直接關閉網域名稱查詢功能。

- 操作指令：
    
    1. 進入工程房：`Router#` 輸入 `conf t`
    2. 輸入禁用指令：`no ip domain-lookup`
    3. 退回存檔：按 `Ctrl + Z` 然後輸入 `copy run start` 存檔。
    
- 效果：設定之後，就算以後指令打錯，系統也會立刻彈出錯誤訊息，絕對不會再卡住！
