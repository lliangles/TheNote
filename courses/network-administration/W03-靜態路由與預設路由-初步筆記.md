## 1. 靜態路由 (Static Routing) 原理

由網路管理員手動鍵入路由表的路徑條目：
- **優點**：
  - 零頻寬開銷（不傳送週期性廣播封包）。
  - 降低 CPU 與記憶體負擔（不需執行複雜路由演算法）。
  - 高度安全（只有網管人員手動指定的路徑才能轉發）。
- **缺點**：
  - 缺乏容錯彈性（線路斷線時無法自動切換備援）。
  - 網路拓撲擴充時維護成本極高。

---

## 2. 靜態路由指令語法

```cisco
Router(config)# ip route <目的網路位址> <子網路遮罩> <下一跳 IP | 本地出介面> [管理距離 AD]
```

### 設定方式比較：
1. **指定下一跳 IP（Next-Hop IP，最推薦）**：
   ```cisco
   Router(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
   ```
   路由器會遞迴查詢（Recursive Lookup）該下一跳 IP 的出介面。
2. **指定本地出介面（Exit Interface）**：
   ```cisco
   Router(config)# ip route 192.168.2.0 255.255.255.0 Serial 0/0/0
   ```
   *注意：若在廣播型乙太網路上直接指定出介面，可能引發大量 Proxy ARP 廣播，消耗頻寬。*

---

## 3. 預設路由 (Default Route / Gateway of Last Resort)

當路由表中找不到任何匹配特定目的地的路徑時，所有封包一律丟往預設路由：
```cisco
Router(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
```
- `0.0.0.0 0.0.0.0` 代表「任何目的網路與任何遮罩」（Quad-Zero）。
- 廣泛應用於**末梢網路（Stub Network）**，將對外流量統一交由 ISP 閘道轉發。

---

## 4. 浮動靜態路由 (Floating Static Route)

利用調高**管理距離（Administrative Distance, AD）**，建立平時休眠、僅在主線路斷線時才啟動的備援路由：
```cisco
! 主線路 (AD 預設為 1)
Router(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

! 備援線路 (手動將 AD 設為 10)
Router(config)# ip route 192.168.2.0 255.255.255.0 10.0.1.2 10
```
