## 1. 路由選擇兩大黃金原則

當路由器收到目的 IP 為 `172.16.1.10` 的封包時：

### 1.1 原則一：最長前綴匹配 (Longest Prefix Match, LPM - 最高裁決權)
- 不管路由是透過何種協定學得（靜態、OSPF、RIP），**遮罩長度最長（最具體、精準）的路徑優先命中**！
- 比較範例：
  - 路徑 A: `172.16.0.0/16` (匹配 16 位元)
  - 路徑 B: `172.16.1.0/24` (匹配 24 位元) $\implies$ **命中此條！**
  - 路徑 C: `0.0.0.0/0` (預設路由，匹配 0 位元)

### 1.2 原則二：管理距離 (Administrative Distance, AD)
若針對**完全相同的目的地與遮罩長度**，由不同路由來源學到，則挑選 **AD 值最低者**放入 Routing Table：

| 路由來源 (Route Source) | 預設管理距離 (Default AD) | 可信度評估 |
| :--- | :---: | :--- |
| **Directly Connected (直連介面)** | **0** | 最可信 |
| **Static Route (靜態路由)** | **1** | 人工明確指定 |
| **EIGRP Summary Route** | **5** | 摘要路徑 |
| **eBGP (外部 BGP)** | **20** | 跨自治系統邊界 |
| **EIGRP (內部)** | **90** | Cisco 高級距離向量 |
| **OSPF** | **110** | 開放最短路徑優先 |
| **IS-IS** | **115** | 中間系統至中間系統 |
| **RIP (v1 / v2)** | **120** | 距離向量 |
| **External EIGRP** | **170** | 外部重分配 |
| **Unknown / Unreachable** | **255** | 不可信，絕不採納 |
