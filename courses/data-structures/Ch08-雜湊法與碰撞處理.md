## 1. 雜湊基本概念 (Hashing Concepts)

- **字典 (Dictionary ADT)**：儲存鍵值與資料對偶 `<Key, Value>`，支援搜尋、插入與刪除。
- **雜湊表 (Hash Table)**：固定大小的連續儲存陣列，透過數學函數 $h(k)$ 將鍵值直接映射至陣列索引（桶位址），期望達到 **$O(1)$** 存取。

### 1.1 雜湊表核心術語 (溫老師 PPT 規範)
- **桶 (Bucket $b$)**：雜湊表中由雜湊函數算出的獨立儲存槽位（索引 $0$ 到 $b-1$）。
- **槽 (Slot $s$)**：每個 Bucket 中所能容納的記錄 (Pair) 數量。通常 $s=1$，亦可有多個槽。
- **鍵值密度 (Key Density)**：$n / T$，其中 $n$ 為實際儲存的識別字數量，$T$ 為所有可能鍵值的總數。
- **載入因子 (Loading Factor $\alpha$)**：
  $$\mathbf{\alpha = \frac{n}{s \cdot b}}$$
  - 衡量雜湊表的擁擠程度。$\alpha$ 越大，空間利用率越高，但發生碰撞的機率也大幅激增。
- **同義字 (Synonyms)**：兩個相異鍵值 $k_1 \ne k_2$，若 $h(k_1) = h(k_2)$，則互為同義字。
- **碰撞 (Collision)**：新鍵值被映射至一個已被其他鍵值佔據的 Bucket。
- **溢位 (Overflow)**：當新鍵值被映射至一個**所有 Slot 皆已滿載**的 Bucket 時，引發溢位。若 $s=1$，則碰撞與溢位同時發生。

## 2. 常用雜湊函數 (Hash Functions)

一個優良的雜湊函數必須具備：計算快速、均勻分散 (Uniform Distribution)、減少碰撞。

### 2.1 除法法 (Division Method)
$$h(k) = k \bmod D$$
- **除數 $D$ 的挑選準則**：
  - 必須小於等於 Bucket 總數 $b$。
  - **最佳選擇**：挑選一個**質數 (Prime Number)**，且避免靠近 2 的冪次方 ($2^p$) 或 10 的冪次方。
  - 若 $D = 2^p$，則 $k \bmod 2^p$ 只取決於鍵值二進制的最後 $p$ 位元，高位元資訊完全丟失，極易聚集！

### 2.2 平方取中法 (Mid-Square Method)
- 將鍵值平方 $k^2$，然後擷取**中間的若干位數**作為 Bucket 位址。
- **原理**：平方後的居中數值是由原鍵值的大多數位元共同乘積計算而來，因此具有極佳的隨機均勻分散特性。
- **範例**：$k = 122 \implies 122^2 = 14884$。若取中間 3 位數，則 $h(122) = 488$。

### 2.3 折疊法 (Folding Method)
將鍵值切分為數個長度相等的片段（除最後一段外），再將各段相加：
1. **移位折疊 (Shift Folding)**：各片段直接對齊相加。
2. **邊界折疊 (Boundary Folding)**：如同摺紙般，將兩側的片段反轉顛倒後再相加。

### 2.4 數位分析法 (Digit Analysis)
- 適用於**靜態檔案 (Static File)**（所有鍵值預先已知）。
- 分析鍵值各個數位的統計分佈，挑選分佈最均勻、偏態最小的若干位數組合成位址。

## 3. 溢位處理技術 (Overflow Handling)

### 3.1 開放定址法 (Open Addressing / Closed Hashing)
當目標 Bucket 滿載時，依特定規則在雜湊表內部探測其他空閒的 Bucket：

#### 1. 線性探測 (Linear Probing)
$$h_i(k) = (h(k) + i) \bmod b, \quad i = 1, 2, \dots, b-1$$
- 順序檢查下一個連續 Bucket。
- **嚴重缺陷：主要聚集 (Primary Clustering)**！
  - 連續被佔據的 Bucket 會形成一個大集團 (Cluster)。
  - 任何落入該集團附近的鍵值，都會被迫拉長探測距離並進一步擴大該集團，導致搜尋效能雪崩式下降。

#### 2. 二次探測 (Quadratic Probing)
$$h_i(k) = (h(k) \pm i^2) \bmod b, \quad i = 1, 2, \dots, \lfloor b/2 \rfloor$$
- 探測跳躍步長為平方數 ($+1, -1, +4, -4, +9, \dots$)，有效打散相鄰的連續聚集。

#### 3. 隨機探測 (Random Probing) 與 雙重雜湊 (Double Hashing / Rehashing)
- 雙重雜湊使用第二個獨立雜湊函數 $h'(k)$ 決定跳躍步長：
  $$h_i(k) = (h(k) + i \cdot h'(k)) \bmod b$$
- 徹底消除主要聚集與次要聚集。

---

### 3.2 鏈結法 (Separate Chaining / Open Hashing)
每個 Bucket 配置一個指標，指向一條單向鏈結串列。所有同義字直接掛載在該串列中：

```text
ht[0] ──> NULL
ht[1] ──> [ "acos" ] ──> [ "atoi" ] ──> [ "atol" ] ──> NULL
ht[2] ──> [ "char" ] ──> [ "ceil" ] ──> [ "cos" ] ──> NULL
ht[3] ──> [ "define" ] ──> NULL
```

- **優點**：
  - 徹底免除主要聚集現象。
  - 刪除操作極其簡便（直接鏈結節點刪除，不必像線性探測需標記墓碑 Tombstone）。
  - 當元素個數超過表長度時仍能正常運作 ($\alpha > 1$)。
- **平均效能分析**：
  - **成功搜尋 (Successful Search)**：$$S_n \approx 1 + \frac{\alpha}{2}$$
  - **失敗搜尋 (Unsuccessful Search)**：$$U_n \approx \alpha$$
