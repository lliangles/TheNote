## 1. 圖的起源、定義與術語 (Graph Definitions)

### 1.1 歷史起源：柯尼斯堡七橋問題 (Königsberg Bridge Problem)
1736 年尤拉 (Euler) 證明：若要不重複走過所有橋樑並回到原點（**尤拉迴路 Eulerian Circuit**），圖中**所有頂點的度數 (Degree) 必須全為偶數**。若要有起點與終點相異的**尤拉路徑 (Eulerian Path)**，則**奇數度數的頂點個數恰好為 2 個**。

### 1.2 圖的術語
- 圖 $G = (V, E)$：$V$ 為頂點有限非空集合，$E$ 為邊的集合。
- **無向圖 (Undirected Graph)**：邊表示為 $(u, v)$；**有向圖 (Directed Graph / Digraph)**：邊表示為 $\langle u, v \rangle$（$u$ 為起點 Head，$v$ 為終點 Tail）。
- **完全圖 (Complete Graph)**：任兩頂點皆有邊相連。包含 $n$ 個頂點的無向完全圖邊數為：
  $$\text{Edges} = \frac{n(n - 1)}{2}$$
- **度數 (Degree)**：無向圖連接該頂點的邊數；有向圖區分為**入度 (In-degree)** 與**出度 (Out-degree)**。
  - 無向圖握手定理：$\sum_{v \in V} \text{degree}(v) = 2 \cdot |E|$。
- **強連通 (Strongly Connected)**：在有向圖中，任意相異頂點對 $u, v$，皆存在從 $u$ 到 $v$ 且從 $v$ 到 $u$ 的有向路徑。

## 2. 圖的五大儲存結構 (Graph Representations)

| 結構名稱 | 空間複雜度 | 優點 | 缺點 / 適用場景 |
| :--- | :---: | :--- | :--- |
| **鄰接矩陣 (Adjacency Matrix)** | $O(n^2)$ | 判斷任兩點是否有邊只需 $O(1)$ | 稀疏圖浪費大量空間；求所有鄰居需 $O(n)$ |
| **鄰接串列 (Adjacency List)** | $O(n + e)$ | 稀疏圖極省空間；遍歷所有鄰居只需 $O(\text{degree})$ | 判定特定邊存在需搜尋鏈結；有向圖求入度困難 |
| **逆鄰接串列 (Inverse Adj List)** | $O(n + e)$ | 專門加速有向圖「入度 (In-degree)」與來源點查找 | 與一般鄰接串列配合使用 |
| **直交串列 (Orthogonal List)** | $O(n + e)$ | 每個節點同時擁有入度與出度指標鏈 | 有向圖專用，兼顧雙向走訪需求 |
| **鄰接多元串列 (Adjacency Multilist)** | $O(n + e)$ | 無向圖每條邊僅需單一節點，被兩頂點串列共用 | 標記「邊是否已被造訪」時極為便捷 |

## 3. 圖的走訪：DFS 與 BFS

```text
DFS (深度優先): 利用 Stack (或遞迴) 一路鑽到底，碰到死胡同才回溯。
BFS (廣度優先): 利用 Queue 一層一層向外擴散走訪。
```

- **時間複雜度比較**：
  - 鄰接串列：$$O(n + e)$$
  - 鄰接矩陣：$$O(n^2)$$

## 4. 雙連通元與關節點 (Biconnected Components & Articulation Points)

### 4.1 關節點 (Articulation Point / Cut-vertex) 定義
若自連通無向圖 $G$ 中刪除頂點 $v$ 及其相連的所有邊後，會使得該圖**分裂為至少兩個連通元件**，則稱 $v$ 為關節點。沒有關節點的連通圖稱為**雙連通圖 (Biconnected Graph)**。

### 4.2 Tarjan DFS 走訪演算法 (`dfn` 與 `low` 數值)
- **`dfn[u]`**：深度優先搜尋時造訪頂點 $u$ 的時間戳編號 (Discovery Time Number)。
- **`low[u]`**：由頂點 $u$ 出發，經由 DFS 樹枝邊向下搜尋、並最多經過一條**後向邊 (Back edge)** 所能到達之祖先節點的最小 `dfn` 值：
  $$low[u] = \min \begin{cases} dfn[u] \\ \min \{ low[w] \mid w \text{ 是 } u \text{ 的子節點} \} \\ \min \{ dfn[w] \mid (u, w) \text{ 是一條後向邊} \} \end{cases}$$

#### 關節點判定兩大準則 (必考)：
1. **樹根節點 (Root of DFS tree)**：是關節點 $\iff$ 擁有 **至少 2 個子節點**。
2. **非樹根節點 $u$**：是關節點 $\iff$ 存在一個子節點 $v$，滿足：
   $$\mathbf{low[v] \ge dfn[u]}$$
   *(意義：子節點 $v$ 無法透過後向邊翻越回 $u$ 的祖先，一旦砍掉 $u$，$v$ 及其子樹即與外部孤立)*。

## 5. 最小成本生成樹 (Minimum Spanning Tree, MST)

包含圖中所有 $n$ 個頂點、且邊權重總和最小的樹（恰好包含 $n-1$ 條邊，無環）。

### 5.1 Kruskal 演算法 (以邊為核心，貪婪策略)
1. 將圖中所有邊依照權重由小到大排序。
2. 依序挑選最小權重邊加入生成樹，若挑選的邊會造成環路則捨棄該邊。
3. 利用 **Disjoint Set (Union-Find)** 偵測兩端點是否屬於同一集合（同集合則代表有環）。
4. **時間複雜度**：$$O(e \log e)$$（適合**邊稀疏圖**）。

### 5.2 Prim 演算法 (以頂點為核心，貪婪擴展)
1. 從任一初始頂點開始，將其納入生成樹頂點集 $S$。
2. 在所有一端在 $S$ 內、另一端在 $S$ 外的邊中，挑選權重最小者，將外部頂點納入 $S$。
3. 重複直到所有 $n$ 個頂點皆納入 $S$。
4. **時間複雜度**：鄰接矩陣為 $$O(n^2)$$；使用 Min-Heap 優化為 $$O(e \log n)$$（適合**邊稠密圖**）。

## 6. 最短路徑演算法 (Shortest Paths)

### 6.1 Dijkstra 演算法 (單源最短路徑，無負權重邊)
- 維護距離陣列 `dist[n]` 與已確認集合 $S$。
- 每輪從尚未確認的頂點中挑選 `dist` 最小者 $u$ 納入 $S$，並對 $u$ 的鄰居進行**鬆弛運算 (Relaxation)**：
  $$\text{if } (dist[u] + cost(u, v) < dist[v]) \implies dist[v] = dist[u] + cost(u, v)$$
- **時間複雜度**：$O(n^2)$。

### 6.2 Bellman-Ford 演算法 (單源最短路徑，允許負權重邊)
- 重複執行 $n-1$ 輪全邊鬆弛。
- **偵測負權環 (Negative Cycle)**：在第 $n$ 輪若仍有邊能成功被鬆弛，代表圖中存在負權環（最短路徑不存在，可無限繞圈變負無窮大）。
- **時間複雜度**：$$O(n \cdot e)$$。

### 6.3 Floyd-Warshall 演算法 (全點對最短路徑 All-Pairs)
- 動態規劃三重迴圈，令 $A^k[i][j]$ 代表只允許使用 $\{0, 1, \dots, k\}$ 作為中間轉折點時，$i$ 到 $j$ 的最短距離：
  $$A^k[i][j] = \min \left( A^{k-1}[i][j], \; A^{k-1}[i][k] + A^{k-1}[k][j] \right)$$
- **時間複雜度**：$$O(n^3)$$，程式極為簡潔。

## 7. 活動網路 (Activity Networks)

### 7.1 AOV 網路與拓撲排序 (Topological Sorting)
- **AOV (Activity-on-Vertex)**：頂點代表任務，有向邊代表優先順序限制。必須為 **DAG (Directed Acyclic Graph, 有向無環圖)**。
- **拓撲排序演算法**：
  1. 計算所有頂點的入度 (In-degree)。
  2. 將所有入度為 0 的頂點壓入堆疊。
  3. Pop 出頂點 $v$ 輸出，並將 $v$ 所有指出的邊刪除（相鄰頂點入度減 1）。
  4. 若有新頂點入度變為 0，則壓入堆疊。
  5. **判斷有向環**：若最終輸出的頂點總數小於 $n$，則圖中**必定存在有向環路**！
- **時間複雜度**：$$O(n + e)$$。

---

### 7.2 AOE 網路與關鍵路徑 (Critical Path Method, CPM)
- **AOE (Activity-on-Edge)**：有向邊代表活動與所需工期，頂點代表**事件 (Event)**（階段里程碑）。
- **事件最早發生時間 $ee[j]$ (Earliest Event Time)**：
  - 由起點順向推展（拓撲順序）：
    $$ee[0] = 0, \quad ee[j] = \max_{i} \{ ee[i] + \text{duration}(i, j) \}$$
- **事件最遲發生時間 $le[i]$ (Latest Event Time)**：
  - 由終點逆向推展（逆拓撲順序）：
    $$le[\text{dest}] = ee[\text{dest}], \quad le[i] = \min_{j} \{ le[j] - \text{duration}(i, j) \}$$
- **活動最早開始時間 $e[k]$** 與 **活動最遲開始時間 $l[k]$**：
  - 設活動 $a_k$ 連接事件 $i \to j$：
    $$e[k] = ee[i]$$
    $$l[k] = le[j] - \text{duration}(a_k)$$
- **關鍵活動 (Critical Activities)**：滿足寬裕時間為 0 的活動：
  $$\mathbf{l[k] - e[k] = 0}$$
- **關鍵路徑 (Critical Path)**：全由關鍵活動構成的路徑，決定了整個工程專案的最短完工時間。
