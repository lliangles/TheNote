## 1. 樹的基本名詞定義 (Terminology)

- **Root（樹根）**：沒有父節點的唯一節點。
- **Degree（度數）**：
  - 節點的度數：該節點擁有的子樹數量（子節點數量）。
  - 樹的度數：整棵樹中所有節點度數的最大值。
- **Leaf / Terminal Node（葉節點 / 終端節點）**：度數為 0 的節點（沒有子節點）。
- **Ancestors（祖先）**：從樹根到該節點路徑上的所有節點。
- **Level / Height / Depth（層級與高度）**：樹根為 Level 1，樹中節點的最大層次即為樹的高度（Height）或深度（Depth）。

---

## 2. 二元樹核心數學定理 (Binary Tree Properties)

> [!IMPORTANT] 必考數學推導定理
> 1. **第 $i$ 層的最大節點數**：$2^{i-1}$（$i \ge 1$）。
> 2. **深度為 $k$ 的二元樹最大總節點數**：$2^k - 1$（$k \ge 1$）。
> 3. **葉節點與度數為 2 節點的關係定理**：
>    設非空二元樹中，度數為 0 的節點數為 $n_0$，度數為 2 的節點數為 $n_2$，則：
>    $$n_0 = n_2 + 1$$
>    *推導簡證*：總邊數 $B = n - 1$，且 $B = n_1 + 2n_2$。聯立 $n = n_0 + n_1 + n_2$ 與 $n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，消去 $n_1$ 即可得 $n_0 = n_2 + 1$。

### 特殊二元樹類型：
- **Full Binary Tree（完滿二元樹）**：深度為 $k$ 且節點數恰好為 $2^k - 1$ 的二元樹。
- **Complete Binary Tree（完整二元樹）**：除最後一層外各層完全填滿，且最後一層節點由左向右依序填入。
- **Skewed Binary Tree（歪斜樹）**：所有節點皆只有左子樹或只有右子樹，退化成鏈結串列。

---

## 3. 二元樹走訪 (Binary Tree Traversals)

以節點 V、左子樹 L、右子樹 R 表示：
1. **前序走訪 (Preorder - VLR)**：拜訪根節點 $\rightarrow$ 走訪左子樹 $\rightarrow$ 走訪右子樹。
2. **中序走訪 (Inorder - LVR)**：走訪左子樹 $\rightarrow$ 拜訪根節點 $\rightarrow$ 走訪右子樹（BST 中序走訪恰為遞增排序！）。
3. **後序走訪 (Postorder - LRV)**：走訪左子樹 $\rightarrow$ 走訪右子樹 $\rightarrow$ 拜訪根節點。
4. **層序走訪 (Level-order)**：利用 Queue 實現 BFS，由上至下、由左至右逐層拜訪。

---

## 4. 二元搜尋樹 (Binary Search Tree, BST)

- **定義**：對任一節點，其左子樹所有鍵值皆小於該節點鍵值；右子樹所有鍵值皆大於該節點鍵值。
- **搜尋與插入時間複雜度**：平均 $O(\log n)$，最差（歪斜樹）$O(n)$。

### BST 節點刪除三大情境：
1. **刪除葉節點**：直接將其父節點相應指標設為 `nullptr` 並釋放空間。
2. **刪除只有單一子節點的節點**：讓父節點直接跨過該節點，指向其唯一的子節點。
3. **刪除擁有兩個子節點的節點**：
   - 尋找**左子樹的最大值**（左子樹最右下節點）或**右子樹的最小值**（右子樹最左下節點）來替換該節點數值。
   - 再轉化為刪除該替換來源節點（必為情況 1 或 2）。

---

## 5. 堆積 (Heap) 與優先權佇列

- **Max Heap（最大堆積）**：一棵 Complete Binary Tree，且任一節點鍵值皆大於等於其子節點鍵值（根節點為最大值）。
- **陣列儲存法則**（索引從 1 開始）：
  - 節點 $i$ 的父節點索引：$\lfloor i/2 \rfloor$
  - 節點 $i$ 的左子節點索引：$2i$
  - 節點 $i$ 的右子節點索引：$2i + 1$
- **插入（Bubble Up）**：放入最後位置，不斷與父節點比較上浮，$O(\log n)$。
- **刪除最大值（Trickle Down）**：取走樹根，將最後一個節點移至樹根，向下比較下沉，$O(\log n)$。
