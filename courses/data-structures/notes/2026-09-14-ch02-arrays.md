Ch2 Array 陣列

1. C++ Class / Struct / Union

· Class：public / protected / private、member function、friend
· 宣告放 .h，實作放 .cpp
· 存取成員：
  · 物件：Object.member
  · 指標：Object->member
· struct：C 的結構
· union：成員共用同一塊記憶體
union ()


2. ADT Array

· Objects：<index, value> 的集合
· Functions：
  · Create(j, list, initValue)
  · Retrieve(i)
  · Store(i, x)

3. C 陣列與指標

· int list[5];
· list 可視為 &list[0]
· *(list + i) 等於 list[i]
· 陣列傳入函式通常不複製，傳的是位址

4. 多項式表示

三種常見表示：

1. 固定係數陣列：coef[MaxDegree+1]
2. 動態配置：coef = new float[degree+1]
3. 只存非零項：term { coef, exp }
   · 適合稀疏多項式
   · 加法：合併同次項，係數相加
   · NewTerm 會擴容：capacity 不足時 capacity *= 2

4. 稀疏矩陣 Sparse Matrix

· 用三元組 <row, column, value> 表示
· 按列儲存，同列中 column 由小到大
· 需要知道：Rows、Cols、Terms

6. 稀疏矩陣轉置

· 直覺法：走訪每個元素，放到 (col, row)
· 效率較差：O(terms * columns)
· 快速轉置 Fast Transpose：
  1. 統計每列有多少非零項
  2. 計算每列起始位置
  3. 把元素搬到正確位置
· 時間：O(terms + columns)

4. 矩陣乘法

· 定義：
  result[i][j] = Σ a[i][k] * b[k][j]
· 稀疏矩陣乘法會利用轉置與 row/column 索引來減少計算

8. 陣列記憶體映射

· 一維：A[i] 位址 = α + i * len
· 二維 row-major：
  Loc(A[m][n]) = α + (m * c + n) * len
· 二維 column-major：
  Loc(A[i][j]) = α + (j * rows + i) * len
· 多維陣列也是用一維陣列模擬

9. 字串與模式匹配

· 字串通常用字元陣列表示
· 常見操作：比較、連接、複製、插入、匹配、列印
· 朴素模式匹配：
  · 逐位比較
  · 最差 O(n*m)
· KMP：
  · 先算 failure function f(j)
  · 利用已匹配資訊，避免重頭比
  · FastFind 可達 O(n+m)
