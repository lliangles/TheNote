## 1. 樹的術語與表示法 (Tree Terminology & Representation)

### 1.1 樹的核心術語
- **度數 (Degree of a node)**：該節點擁有的子樹數量（子節點個數）。
- **樹的度數 (Degree of a tree)**：樹中所有節點度數的最大值。
- **葉節點 / 終端節點 (Leaf / Terminal Node)**：度數為 0 的節點。
- **階層 (Level)**：若根節點位於 Level 1，則其子節點位於 Level 2，以此類推。
- **高度 / 深度 (Height / Depth)**：樹中節點所處的最大階層數。
- **祖先 (Ancestors) 與 子孫 (Descendants)**：從根節點到該節點路徑上所有節點為祖先；以該節點為根的子樹中所有節點為子孫。

---

### 1.2 樹的內部表示法：左小孩-右兄弟表示法 (LCRS)
若以固定分支度 $k$ 宣告節點（每個節點 $k$ 個指標欄位），當樹傾斜時會浪費大量指標空間：
> **引理 5.1**：若 $T$ 為包含 $n$ 個節點、度數為 $k$ 的 $k$ 元樹，每個節點固定擁有 $k$ 個指標，則空指標總數為：
> $$\text{Null Pointers} = n(k - 1) + 1$$
> *(例如 $k=3, n=10$ 時，總共 30 個指標中就有 21 個是 NULL！)*

**最佳解法：左小孩-右兄弟表示法 (Left Child-Right Sibling, LCRS)**：
每個節點僅需兩個指標欄位：
1. `LeftChild`：指向該節點的第一個親生小孩 (Oldest Child)。
2. `RightSibling`：指向該節點緊鄰的下一個親兄弟 (Next Sibling)。
*所有任意度數的樹，皆可透過 LCRS 完美轉換為二元樹！*

## 2. 二元樹 (Binary Tree) 核心定理與數學證明

### 2.1 二元樹的定義與分類
二元樹為包含有限個節點的集合，可以是空集合，或由根節點與兩棵互斥的左子樹、右子樹組成（**嚴格區分左右**）。
- **滿二元樹 (Full Binary Tree)**：深度為 $k$ 且擁有 $2^k - 1$ 個節點的二元樹。
- **完全二元樹 (Complete Binary Tree)**：若一棵深度為 $k$、擁有 $n$ 個節點的二元樹，其所有節點與深度 $k$ 的滿二元樹編號 1 到 $n$ 的位置完全一一對應。

---

### 2.2 二元樹核心引理與證明

#### 引理 5.2：最大節點數
二元樹在第 $i$ 層最多有 **$2^{i-1}$** 個節點 ($i \ge 1$)。深度為 $k$ 的二元樹最多有 **$2^k - 1$** 個節點 ($k \ge 1$)。

#### 引理 5.4：葉節點與雙子節點的關係證明 (期末必考)
> **定理**：在任何非空的二元樹中，若度數為 0 的葉節點數為 $n_0$，度數為 2 的節點數為 $n_2$，則恆滿足：
> $$\mathbf{n_0 = n_2 + 1}$$

**完整數學證明**：
1. 設樹中度數為 1 的節點數為 $n_1$。則樹的總節點數 $n$ 為：
   $$n = n_0 + n_1 + n_2 \quad \text{--- (式 1)}$$
2. 接著計算樹中的**總分支數 (Total Branches, 邊數 $B$)**：
   - 每個分支皆由某個節點向下發出：度數為 1 的節點發出 1 條分支，度數為 2 的節點發出 2 條分支，度數為 0 的節點發出 0 條分支：
     $$B = n_1 + 2n_2$$
   - 另一方面，除了根節點之外，每個節點上方皆恰好連接著 1 條進入分支，因此總分支數等於總節點數減 1：
     $$B = n - 1$$
   - 聯立得：
     $$n - 1 = n_1 + 2n_2 \implies n = n_1 + 2n_2 + 1 \quad \text{--- (式 2)}$$
3. 將 (式 1) 與 (式 2) 等號左邊相消：
   $$n_0 + n_1 + n_2 = n_1 + 2n_2 + 1$$
   $$n_0 + n_2 = 2n_2 + 1 \implies \mathbf{n_0 = n_2 + 1} \quad \blacksquare$$

---

### 2.3 陣列表示法索引公式 (Array Representation)
若將完全二元樹依編號 $1$ 到 $n$ 依序存入一維陣列 `tree[1..n]`，則對任意節點 $i$ ($1 \le i \le n$)：
1. **父節點 `parent(i)`**：位於 $\lfloor i / 2 \rfloor$（若 $i=1$ 則為根節點，無父節點）。
2. **左子節點 `left_child(i)`**：位於 $2i$（若 $2i > n$，則無左子節點）。
3. **右子節點 `right_child(i)`**：位於 $2i + 1$（若 $2i + 1 > n$，則無右子節點）。

## 3. 樹的走訪演算法 (Tree Traversals)

遍歷每個節點恰好一次，產生線性序列：

```text
       [+]
      /   \
    [*]    [E]
   /   \
 [/]   [D]
 / \
[A] [B]
```

### 3.1 三大遞迴走訪
1. **中序走訪 (Inorder Traversal, L-D-R)**：`A / B * D + E` $\implies$ 對應 **中序運算式 (Infix)**。
2. **前序走訪 (Preorder Traversal, D-L-R)**：`+ * / A B D E` $\implies$ 對應 **前序運算式 (Prefix)**。
3. **後序走訪 (Postorder Traversal, L-R-D)**：`A B / D * E +` $\implies$ 對應 **後序運算式 (Postfix)**。

---

### 3.2 非遞迴中序走訪 (Iterative Inorder using Stack)
利用顯式堆疊模擬系統遞迴：

```cpp
void Tree::NonrecInorder() {
    Stack<TreeNode*> s;
    TreeNode *currentNode = root;
    while (true) {
        while (currentNode) { // 一路向左鑽到底，將沿途節點全部壓入堆疊
            s.Push(currentNode);
            currentNode = currentNode->leftChild;
        }
        if (s.IsEmpty()) return; // 堆疊空且無待訪節點，走訪結束
        currentNode = *s.Pop();
        cout << currentNode->data << " "; // 拜訪中序節點 (Data)
        currentNode = currentNode->rightChild; // 轉向右子樹
    }
}
```

### 3.3 階層走訪 (Level-Order Traversal using Queue)
依深度由上至下、由左至右逐層走訪：

```cpp
void Tree::LevelOrder() {
    Queue<TreeNode*> q;
    TreeNode *currentNode = root;
    while (currentNode) {
        cout << currentNode->data << " ";
        if (currentNode->leftChild) q.Push(currentNode->leftChild);
        if (currentNode->rightChild) q.Push(currentNode->rightChild);
        if (q.IsEmpty()) return;
        currentNode = *q.Pop();
    }
}
```

## 4. 引線二元樹 (Threaded Binary Tree)

### 4.1 核心動機：零堆疊、常數輔助空間走訪
在包含 $n$ 個節點的二元鏈結樹中，共有 $2n$ 個指標欄位，但僅消耗 $n-1$ 條分支，高達 **$n+1$ 個空指標 (NULL)**。
引線二元樹將這些空指標充分利用：
- 若節點的 `rightChild == NULL` $\implies$ 改指向該節點在中序走訪下的**後繼者 (Inorder Successor)**，標記 `rightThread = true`。
- 若節點的 `leftChild == NULL` $\implies$ 改指向該節點在中序走訪下的**前驅者 (Inorder Predecessor)**，標記 `leftThread = true`。

```cpp
class ThreadedNode {
public:
    char data;
    ThreadedNode *leftChild, *rightChild;
    bool leftThread, rightThread; // false: 一般子節點指標; true: 引線 (Thread)
};
```

---

### 4.2 引線樹尋找中序後繼者演算法 `Next()`
```cpp
ThreadedNode* ThreadedTree::InorderSuccessor(ThreadedNode *current) {
    ThreadedNode *r = current->rightChild;
    if (!current->rightThread) { // 若是實體右子樹，則後繼者為該右子樹中最左側的節點！
        while (!r->leftThread) r = r->leftChild;
    }
    return r; // 若 rightThread == true，則直接沿著引線抵達後繼者！
}

void ThreadedTree::Inorder() {
    ThreadedNode *p = HeadNode;
    while (true) {
        p = InorderSuccessor(p);
        if (p == HeadNode) return; // 回到標頭節點，走訪結束
        cout << p->data << " ";
    }
}
```
- **複雜度**：走訪整棵樹耗時 $O(n)$，**額外輔助空間完全為 $O(1)$**（不需任何 Stack 或 Queue）！

## 5. 堆積與優先權佇列 (Heaps & Priority Queues)

優先權佇列 (Priority Queue) 允許以任意順序加入元素，但取出時永遠是最高 (或最低) 優先權者。
- **最大堆積 (Max Heap)**：一棵完全二元樹，且每個節點的鍵值大於或等於其所有子節點鍵值。
- **最小堆積 (Min Heap)**：一棵完全二元樹，且每個節點的鍵值小於或等於其所有子節點鍵值。

```cpp
template <class T>
class MaxHeap {
private:
    T *heap;
    int heapSize, capacity;
public:
    MaxHeap(int cap = 10) : capacity(cap), heapSize(0) { heap = new T[capacity + 1]; }
    void Push(const T& e);
    T Pop();
};
```

### 5.1 堆積插入演算法 (`Push` - Percolate Up / 向上濾波)
將新元素放在樹底最後一個位置 (`heap[++heapSize]`)，若大於父節點則與父節點對調，持續向上調整：
```cpp
template <class T>
void MaxHeap<T>::Push(const T& e) {
    if (heapSize == capacity) throw "Heap Full";
    int currentNode = ++heapSize;
    // 向上濾波 (Percolate Up)
    while (currentNode != 1 && heap[currentNode / 2] < e) {
        heap[currentNode] = heap[currentNode / 2]; // 父節點下移
        currentNode /= 2;
    }
    heap[currentNode] = e;
}
```
- **插入時間複雜度**：$$O(\log n)$$

### 5.2 堆積刪除演算法 (`Pop` - Percolate Down / 向下調整)
取出根節點 `heap[1]`，將最後一個節點 `heap[heapSize--]` 暫存，自根部向下尋找較大的子節點進行替換：
```cpp
template <class T>
T MaxHeap<T>::Pop() {
    if (heapSize == 0) throw "Heap Empty";
    T maxItem = heap[1];
    T lastItem = heap[heapSize--];
    int currentNode = 1;
    int child = 2; // 左小孩

    while (child <= heapSize) {
        // child 移向兩小孩中較大者
        if (child < heapSize && heap[child] < heap[child + 1]) child++;
        if (lastItem >= heap[child]) break; // 找到安置位置
        heap[currentNode] = heap[child];    // 較大小孩上移
        currentNode = child;
        child *= 2;
    }
    heap[currentNode] = lastItem;
    return maxItem;
}
```
- **刪除時間複雜度**：$$O(\log n)$$

## 6. 二元搜尋樹 (Binary Search Tree, BST)

### 6.1 BST 性質與搜尋
- **性質**：非空左子樹所有鍵值 $<$ 根節點鍵值 $<$ 非空右子樹所有鍵值；左右子樹皆為 BST。
- **搜尋時間**：取決於樹高 $h$。最佳/平均 $O(\log n)$；若退化為傾斜樹則最差為 $O(n)$。

### 6.2 二元搜尋樹之刪除運算 (Deletion - 三種情況)
1. **刪除葉節點**：直接將其父節點對應指標設為 `nullptr` 並釋放記憶體。
2. **刪除只有單一小孩的節點**：直接將其父節點接往其唯一的子節點（繞過該節點）。
3. **刪除擁有兩個小孩的節點**：
   - 尋找其左子樹最大值 (**中序前驅者 Inorder Predecessor**) 或右子樹最小值 (**中序後繼者 Inorder Successor**)。
   - 將該值複製至當前節點。
   - 轉為刪除該前驅者或後繼者節點（此時該點最多只有 1 個小孩，退化為情況 1 或 2）。

## 7. 選擇樹 (Selection Trees) 與 $k$ 路合併

在外部排序中將 $k$ 個已排序序列合併為一個時，使用選擇樹可大幅降低比較次數：

| 類型 | 內部節點記錄內容 | 重整比較機制 (Restructuring) |
| :--- | :--- | :--- |
| **贏者樹 (Winner Tree)** | 記錄左右子節點中的**勝者 (較小者)** | 每次輸出勝者後，需與兄弟節點比較勝負，重整耗時 $O(\log_2 k)$ |
| **輸者樹 (Loser Tree)** | 內部節點記錄**輸者 (較大者)**，最終勝者放在 `tree[0]` | 重整時**只需直接與父節點所記的輸者比較**，不需存取兄弟節點，簡化流程 |

## 8. 互斥集與聯集尋找 (Disjoint Set Union-Find)

樹可用來表示互斥集合，根節點代表集合名稱。

### 8.1 加權聯集規則 (Weighted Union Rule)
避免簡單 Union 造成一條細長的退化鏈（深度 $O(n)$）：
> **加權規則**：若樹根 $i$ 的節點數量少於樹根 $j$ 的節點數量，則將樹 $i$ 掛載為樹 $j$ 的子節點。
> （在實作上，根節點陣列值存入負的節點數量：`parent[root] = -count`）。

- **引理 5.5**：採用 Weighted Union，包含 $m$ 個節點的樹其高度最大為：
  $$\text{Height} \le \lfloor \log_2 m \rfloor + 1$$

---

### 8.2 摺疊尋找規則 (Collapsing Find / Path Compression)
在執行 `Find(i)` 沿途往上尋找根節點的同時，將路徑上所有節點的父指標直接指向根節點！

```cpp
int CollapsingFind(int i, int parent[]) {
    int root = i;
    while (parent[root] > 0) root = parent[root]; // 找到真正的樹根
    // 摺疊壓縮路徑
    int current = i;
    while (current != root) {
        int next = parent[current];
        parent[current] = root; // 直連根節點！
        current = next;
    }
    return root;
}
```

> **綜合複雜度分析**：
> 同時採用 Weighted Union 與 Collapsing Find，執行一連串 $m$ 次 Find 與 $n$ 次 Union 的總時間為：
> $$\mathbf{O(m \cdot \alpha(m, n))}$$
> 其中 $\alpha$ 為**反阿克曼函數 (Inverse Ackermann function)**。在所有可見的宇宙物理常數範圍內，$\alpha(m, n) \le 4$，其執行效率與**線性時間 $O(m)$ 無異**！

## 9. 相異二元樹個數與卡特蘭數 (Catalan Number)

- **二元樹重構必備條件**：
  - 給定 Preorder + Inorder $\implies$ 可唯一決定一棵二元樹。
  - 給定 Postorder + Inorder $\implies$ 可唯一決定一棵二元樹。
  - **Preorder + Postorder $\implies$ 無法唯一決定**（無法分辨左子樹還是右子樹）。
- **$n$ 個節點所能構成的相異二元樹型態數量**：
  $$b_n = \frac{1}{n + 1} \binom{2n}{n} = \frac{(2n)!}{(n + 1)! \, n!}$$
  - $n = 1 \implies b_1 = 1$
  - $n = 2 \implies b_2 = 2$
  - $n = 3 \implies b_3 = 5$
  - $n = 4 \implies b_4 = 14$
