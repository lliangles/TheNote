## 1. C++ 類別、結構與聯合體 (Class, Struct, Union)

在 C++ 中設計資料結構時，資料成員的組織與封裝方式至關重要：

| 類型 | 預設成員權限 | 記憶體分配特性 | 應用場景 |
| :--- | :---: | :--- | :--- |
| **`class`** | `private` | 所有成員擁有各自獨立的記憶體空間 | 實作 ADT，貫徹資料封裝與資訊隱藏 |
| **`struct`** | `public` | 所有成員擁有各自獨立的記憶體空間 | 實作純資料傳遞物件 (如 `Term`, `Triple`) |
| **`union`** | `public` | 所有成員**共用同一塊記憶體**（以最大成員為準） | 節省記憶體，同一時間只存一種型態的變數 |

```cpp
// C++ 典型的 ADT 類別骨架
class Rectangle {
private:
    int xLow, yLow, height, width; // 私有資料成員，外部無法直接竄改
public:
    Rectangle(int x = 0, int y = 0, int h = 0, int w = 0); // 建構子
    ~Rectangle();                                          // 解構子
    int GetHeight() const { return height; }
    int GetWidth() const { return width; }
    int Area() const { return height * width; }
};
```

## 2. 一元多項式 (Polynomial) 表示與相加運算

### 2.1 內部表示法設計
給定多項式 $A(x) = 3x^{20} + 2x^5 + 4$ 與 $B(x) = x^4 + 10x^3 + 3x^2 + 1$：
- 若用指數當索引的陣列 `coef[21]`：對於高次稀疏多項式（如 $x^{1000} + 1$）會浪費大量空間。
- **只存非零項 (Non-zero Terms)**：使用 Term 陣列儲存 `<係數, 指數>` 對組。

```cpp
struct Term {
    float coef;  // 係數 (Coefficient)
    int exp;     // 指數 (Exponent)
};

class Polynomial {
private:
    Term *termArray; // 動態配置之非零項陣列
    int capacity;    // 陣列容量
    int terms;       // 實際非零項個數
public:
    Polynomial();
    void NewTerm(float theCoeff, int theExp);
    Polynomial Add(const Polynomial &b);
};
```

### 2.2 多項式相加演算法 `Polynomial::Add`
相加邏輯類似雙指標歸併 (Two Pointers Merge)：
- 指標 `aPos` 與 `bPos` 分別遍歷 $A(x)$ 與 $B(x)$ 的非零項。
- **情況 1**：$A$ 的指數等於 $B$ 的指數 $\implies$ 係數相加，若不為 0 則加入結果多項式。
- **情況 2**：$A$ 的指數大於 $B$ 的指數 $\implies$ 將 $A$ 的項加入結果，`aPos++`。
- **情況 3**：$B$ 的指數大於 $A$ 的指數 $\implies$ 將 $B$ 的項加入結果，`bPos++`。
- 時間複雜度：$O(m + n)$，其中 $m, n$ 分別為兩多項式的非零項個數。

```cpp
Polynomial Polynomial::Add(const Polynomial &b) {
    Polynomial c;
    int aPos = 0, bPos = 0;
    while (aPos < terms && bPos < b.terms) {
        if (termArray[aPos].exp == b.termArray[bPos].exp) {
            float sum = termArray[aPos].coef + b.termArray[bPos].coef;
            if (sum != 0) c.NewTerm(sum, termArray[aPos].exp);
            aPos++; bPos++;
        } else if (termArray[aPos].exp < b.termArray[bPos].exp) {
            c.NewTerm(b.termArray[bPos].coef, b.termArray[bPos].exp);
            bPos++;
        } else {
            c.NewTerm(termArray[aPos].coef, termArray[aPos].exp);
            aPos++;
        }
    }
    // 收集剩餘項
    for (; aPos < terms; aPos++) c.NewTerm(termArray[aPos].coef, termArray[aPos].exp);
    for (; bPos < b.terms; bPos++) c.NewTerm(b.termArray[bPos].coef, b.termArray[bPos].exp);
    return c;
}
```

## 3. 稀疏矩陣 (Sparse Matrices) 與轉置演算法

### 3.1 三元組 (Triple) 儲存結構
當一個 $m \times n$ 矩陣中絕大多數元素為 0 時，稱為**稀疏矩陣**。採用三元組 `<row, col, value>` 儲存，且依列主序排序：
- 第 0 項儲存矩陣元資料：`<rows, cols, terms>`。

```cpp
class MatrixTerm {
public:
    int row, col, value;
};

class SparseMatrix {
private:
    int rows, cols, terms;
    MatrixTerm smArray[MAX_TERMS];
public:
    SparseMatrix Transpose();     // 直觀轉置 O(terms * cols)
    SparseMatrix FastTranspose(); // 快速轉置 O(terms + cols)
};
```

---

### 3.2 直觀矩陣轉置 (Intuitive Transpose)
外層迴圈遍歷目標矩陣的每一列（即原矩陣的每一行 `0` 到 `cols - 1`），內層掃描所有非零項：

```cpp
SparseMatrix SparseMatrix::Transpose() {
    SparseMatrix b;
    b.rows = cols;
    b.cols = rows;
    b.terms = terms;
    if (terms > 0) {
        int currentB = 0;
        for (int c = 0; c < cols; c++) {       // 遍歷每一行
            for (int i = 0; i < terms; i++) {  // 掃描所有非零項
                if (smArray[i].col == c) {
                    b.smArray[currentB].row = smArray[i].col;
                    b.smArray[currentB].col = smArray[i].row;
                    b.smArray[currentB].value = smArray[i].value;
                    currentB++;
                }
            }
        }
    }
    return b;
}
```
- **時間複雜度**：$$O(\text{terms} \times \text{cols})$$
- 若矩陣非零項較多時，$\text{terms} \approx \text{rows} \times \text{cols}$，則複雜度退化為 $$O(\text{rows} \times \text{cols}^2)$$。

---

### 3.3 快速矩陣轉置 (Fast Matrix Transpose)

> [!IMPORTANT]
> **溫敏淦老師 PPT 重點推導**：利用空間換取時間，預先統計每行非零項個數與轉置後的起始位置，將時間複雜度降為線性階 **$O(\text{terms} + \text{cols})$**！

#### 核心三步驟：
1. **統計每行非零項個數**：配置 `rowTerms[cols]` 陣列，走訪一次原矩陣，每遇到一個三元組即累加對應行的計數。
2. **計算各行轉置後的起始索引**：配置 `startingPos[cols]` 陣列，滿足：
   $$startingPos[0] = 0$$
   $$startingPos[i] = startingPos[i-1] + rowTerms[i-1]$$
3. **單趟移動非零項**：再次遍歷原矩陣，根據 `startingPos[col]` 取得目的索引並填入，隨後將其遞增 1。

```cpp
SparseMatrix SparseMatrix::FastTranspose() {
    SparseMatrix b;
    b.rows = cols;
    b.cols = rows;
    b.terms = terms;

    if (terms > 0) {
        int *rowTerms = new int[cols];
        int *startingPos = new int[cols];

        // 步驟 1: 初始化並統計各行非零項數量 (耗時 O(cols) + O(terms))
        for (int i = 0; i < cols; i++) rowTerms[i] = 0;
        for (int i = 0; i < terms; i++) rowTerms[smArray[i].col]++;

        // 步驟 2: 計算轉置後各行在 b 中的起始位置 (耗時 O(cols))
        startingPos[0] = 0;
        for (int i = 1; i < cols; i++)
            startingPos[i] = startingPos[i - 1] + rowTerms[i - 1];

        // 步驟 3: 依序將項放置至正確目標位置 (耗時 O(terms))
        for (int i = 0; i < terms; i++) {
            int j = startingPos[smArray[i].col];
            b.smArray[j].row = smArray[i].col;
            b.smArray[j].col = smArray[i].row;
            b.smArray[j].value = smArray[i].value;
            startingPos[smArray[i].col]++; // 下一個同行的項往後放
        }

        delete[] rowTerms;
        delete[] startingPos;
    }
    return b;
}
```

#### 兩種轉置演算法全面對照表：
| 演算法 | 時間複雜度 (Time Complexity) | 額外空間複雜度 (Space) | 運作特性 |
| :--- | :---: | :---: | :--- |
| **直觀轉置 (Intuitive)** | $O(\text{terms} \times \text{cols})$ | $O(1)$ | 雙層迴圈暴力掃描，隨行數增加而變慢 |
| **快速轉置 (Fast Transpose)** | $\mathbf{O(\text{terms} + \text{cols})}$ | $O(\text{cols})$ | 三次線性掃描，效率極高，考題必算 |

## 4. 多維陣列記憶體定址映射 (Memory Mapping)

電腦記憶體為一維線性連續空間。將高維邏輯結構映射到一維實體位址主要有兩種順序：

```text
二維陣列 A[rows][cols]，元素大小 len bytes，基底位址 α = Loc(A[0][0])
```

### 4.1 列主序 (Row-Major Order)
以列為單位優先儲存（C/C++ 採用）：
$$\text{Loc}(A[i][j]) = \alpha + [i \cdot cols + j] \cdot len$$

- **推廣：帶有下界 $l_1, l_2$ 與上界 $u_1, u_2$**：
  $$\text{Loc}(A[i][j]) = \alpha + [(i - l_1) \cdot (u_2 - l_2 + 1) + (j - l_2)] \cdot len$$

### 4.2 行主序 (Column-Major Order)
以行為單位優先儲存（FORTRAN 採用）：
$$\text{Loc}(A[i][j]) = \alpha + [j \cdot rows + i] \cdot len$$

- **推廣：帶有下界 $l_1, l_2$ 與上界 $u_1, u_2$**：
  $$\text{Loc}(A[i][j]) = \alpha + [(j - l_2) \cdot (u_1 - l_1 + 1) + (i - l_1)] \cdot len$$

### 4.3 $n$ 維陣列通用列主序公式
對於陣列 $A[u_1][u_2]\dots[u_n]$，元素 $A[i_1][i_2]\dots[i_n]$ 的位址偏移量為：
$$\text{Offset} = i_1 \cdot (u_2 u_3 \dots u_n) + i_2 \cdot (u_3 u_4 \dots u_n) + \dots + i_{n-1} \cdot u_n + i_n$$
$$\text{Loc}(A[i_1][i_2]\dots[i_n]) = \alpha + \left( \sum_{j=1}^{n} i_j \prod_{k=j+1}^{n} u_k \right) \cdot len$$

## 5. 字串比對與 KMP 演算法 (Knuth-Morris-Pratt Algorithm)

### 5.1 暴力比對 (Naive Pattern Matching)
若目標字串 $T$ 長度為 $m$，樣式字串 $P$ 長度為 $n$：
- 每次比對失敗，文字指標 $T$ 回退至起始點的下一個字元，樣式指標 $P$ 回退至 0。
- 最壞情況時間複雜度：$O(m \cdot n)$（例如 $T = \text{aaaaab}, P = \text{aab}$）。

---

### 5.2 KMP 失敗函數 (Failure Function $f[j]$)
KMP 核心精神：**利用樣式本身已比對成功的前綴資訊，使得文字指標永不回退**！

> **失敗函數定義**：
> 對於樣式字串 $P = p_0 p_1 \dots p_{n-1}$，位置 $j$ 的失敗函數值 $f[j]$ 定義為：
> $$f[j] = \begin{cases} \max \{ k \mid 0 \le k < j \text{ 且 } p_0 p_1 \dots p_k = p_{j-k} \dots p_j \} & \text{若存在滿足的前綴} \\ -1 & \text{其他情況} \end{cases}$$
> 
> （意即：在子字串 $P[0 \dots j]$ 中，最長的「真前綴 (Proper Prefix)」等於「真後綴 (Proper Suffix)」的長度減 1）。

#### 手算推導範例：`pat = 'abcabcacab'`
讓我們依據定義逐一計算每個字元的 $f[j]$：

| $j$ | $P[j]$ | 子字串 $P[0 \dots j]$ | 相等的最長前綴與後綴 | $k$ | $f[j]$ |
| :---: | :---: | :--- | :--- | :---: | :---: |
| 0 | `a` | `a` | 無真前後綴 | - | **-1** |
| 1 | `b` | `ab` | 無相同前後綴 | - | **-1** |
| 2 | `c` | `abc` | 無相同前後綴 | - | **-1** |
| 3 | `a` | `abca` | `a` == `a` | 0 | **0** |
| 4 | `b` | `abcab` | `ab` == `ab` | 1 | **1** |
| 5 | `c` | `abcabc` | `abc` == `abc` | 2 | **2** |
| 6 | `a` | `abcabca` | `abca` == `abca` | 3 | **3** |
| 7 | `c` | `abcabcac` | 無相符前綴 | - | **-1** |
| 8 | `a` | `abcabcaca` | `a` == `a` | 0 | **0** |
| 9 | `b` | `abcabcacab` | `ab` == `ab` | 1 | **1** |

---

### 5.3 KMP C++ 實作程式碼

```cpp
// 1. 建立失敗函數陣列
void FailureFunction(char *pat, int lengthP, int *f) {
    f[0] = -1;
    for (int j = 1; j < lengthP; j++) {
        int i = f[j - 1];
        while ((pat[j] != pat[i + 1]) && (i >= 0))
            i = f[i];
        if (pat[j] == pat[i + 1])
            f[j] = i + 1;
        else
            f[j] = -1;
    }
}

// 2. KMP 快速字串比對
int KMP_Find(char *string, char *pat, int lengthS, int lengthP, int *f) {
    int posS = 0, posP = 0;
    while (posS < lengthS && posP < lengthP) {
        if (string[posS] == pat[posP]) {
            posS++;
            posP++;
        } else {
            if (posP == 0) posS++;
            else posP = f[posP - 1] + 1; // 樣式指標跳至失敗函數引導的位置
        }
    }
    if (posP < lengthP) return -1; // 沒找到
    else return posS - lengthP;    // 回傳比對成功的起始索引
}
```
- **KMP 時間複雜度**：$$O(\text{Length}(string) + \text{Length}(pat))$$
