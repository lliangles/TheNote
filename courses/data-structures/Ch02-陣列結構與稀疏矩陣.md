## 1. C++ Class, Struct 與 Union 比較

| 特性 | `class` | `struct` | `union` (聯集) |
|:---|:---|:---|:---|
| **預設存取權限** | `private` | `public` | `public` |
| **記憶體佈局** | 每個成員佔用獨立空間 | 每個成員佔用獨立空間 | **所有成員共用同一塊記憶體**（以最大成員為準） |
| **主要用途** | 物件導向封裝、商業邏輯 | 單純資料聚集（POD） | 節省空間或型態雙重視角轉換 |

```cpp
// 宣告放在 .h 檔，實作放在 .cpp 檔
class Rectangle {
private:
    int width, height;
public:
    Rectangle(int w, int h) : width(w), height(h) {}
    int GetArea() { return width * height; }
};

// 成員存取方式：
Rectangle r(10, 20);
r.GetArea();         // 物件實體使用 . 運算子
Rectangle *ptr = &r;
ptr->GetArea();      // 指標使用 -> 運算子
```

## 2. 抽象資料型別 ADT Array

陣列本質上是一組 `<index, value>`（索引與數值）的有序配對集合：

```cpp
class Array {
public:
    Array(int size);               // 建立給定大小的陣列
    Item Retrieve(int index);      // 讀取指定索引的值 O(1)
    void Store(int index, Item x); // 寫入數值至指定索引 O(1)
};
```

- 在 C/C++ 中，陣列名稱 `list` 可視為第一個元素的位址 `&list[0]`。
- 指標位移：`*(list + i)` 完全等價於 `list[i]`。

## 3. 多項式表示法 (Polynomial Representations)

設多項式為 $P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$：

### 三種實作策略對比：

1. **固定大小係數陣列**：`float coef[MaxDegree + 1];`
   - 優點：存取各次項係數極快 $O(1)$。
   - 缺點：若遇到稀疏多項式（如 $x^{1000} + 1$），配置 1001 個欄位卻只用 2 個，極度浪費空間。
2. **動態配置陣列**：`coef = new float[degree + 1];`
   - 依據實際最高次方配置，略微彈性，但仍無法根本解決極端稀疏的浪費問題。
3. **非零項陣列表示法（推薦！）**：
   - 定義結構體 `Term { float coef; int exp; };`。
   - 只儲存係數不為零的項目。
   - 多項式相加演算法：類似雙指標合併（Two Pointers），指數大者先放入結果陣列；若指數相等則係數相加，若相加為 0 則略過。

## 4. 稀疏矩陣與轉置演算法 (Sparse Matrix & Transpose)

### (1) 三元組表示法 (Tri-tuple)
若矩陣中大部分元素為 0，改用三元組儲存非零項：`<row, col, value>`。
- 排序規則：優先按 `row` 遞增排序，同 `row` 內按 `col` 遞增排序。
- 矩陣中儲存三項基本屬性：`Rows`, `Cols`, `Terms` (非零項總數)。

### (2) 快速轉置演算法 (Fast Transpose)

> [!TIP] 考試必考演算法與複雜度對比！
> - **直覺轉置法 (Ordinary Transpose)**：外層迴圈走訪每一欄（$0$ 到 $\text{Cols}-1$），內層走訪所有非零項。時間複雜度為 $O(\text{terms} \times \text{cols})$。若 $\text{terms} \approx \text{rows} \times \text{cols}$，最差達 $O(\text{rows} \times \text{cols}^2)$。
> - **快速轉置法 (Fast Transpose)**：時間複雜度大幅優化為 **$O(\text{terms} + \text{cols})$**！

#### 快速轉置三大步驟：
1. **統計每欄非零項數量**：建立 `RowSize[cols]` 陣列，統計原矩陣中每一欄各有幾個非零項（即轉置後每一列的元素量）。
2. **計算轉置後每列的起始位置**：建立 `RowStart[cols]` 陣列：
   - `RowStart[0] = 0;`
   - `RowStart[i] = RowStart[i - 1] + RowSize[i - 1];`
3. **定位並直接放入新矩陣**：循序走訪原矩陣的每個非零項，根據其欄位 `col`，直接查出其在新矩陣的索引位置 `j = RowStart[col]++`，放入後將該欄起始位置往後推一位。

```cpp
void FastTranspose(Term a[], Term b[]) {
    b[0].row = a[0].col; b[0].col = a[0].row; b[0].value = a[0].value;
    int numTerms = a[0].value;
    int numCols = a[0].col;
    if (numTerms <= 0) return;

    int *rowSize = new int[numCols]();
    int *rowStart = new int[numCols]();

    for (int i = 1; i <= numTerms; i++) rowSize[a[i].col]++;
    rowStart[0] = 1;
    for (int i = 1; i < numCols; i++) rowStart[i] = rowStart[i - 1] + rowSize[i - 1];

    for (int i = 1; i <= numTerms; i++) {
        int j = rowStart[a[i].col]++;
        b[j].row = a[i].col;
        b[j].col = a[i].row;
        b[j].value = a[i].value;
    }
    delete[] rowSize;
    delete[] rowStart;
}
```

## 5. 陣列記憶體位址映射公式 (Memory Address Mapping)

設起始記憶體位址為 $\alpha$，每個元素佔用 $d$ 個記憶體單位（bytes）：

### (1) 一維陣列 $A[0 \dots n-1]$：
$$Loc(A[i]) = \alpha + i \times d$$
若索引從 $1$ 開始 ($A[1 \dots n]$)：
$$Loc(A[i]) = \alpha + (i - 1) \times d$$

### (2) 二維陣列 $A[m][n]$（$m$ 列 $n$ 行）：
- **Row-Major Order（以列為主，C/C++/Java 預設）**：
  同一列的元素連續存放在記憶體中：
  $$Loc(A[i][j]) = \alpha + (i \times n + j) \times d$$
- **Column-Major Order（以行為主，Fortran 預設）**：
  同一行的元素連續存放在記憶體中：
  $$Loc(A[i][j]) = \alpha + (j \times m + i) \times d$$

> [!EXAMPLE] 實戰計算題範例
> 設二維陣列 $A[10][20]$，每個元素佔 4 bytes，起始位址 $\alpha = 1000$。以 Row-Major 計算 $A[3][5]$ 的位址：
> - $Loc(A[3][5]) = 1000 + (3 \times 20 + 5) \times 4 = 1000 + 65 \times 4 = 1260$。

## 6. 字串模式匹配 (Pattern Matching)

- **Naive 朴素法**：逐一比對主字串與樣式字串，比對失敗時指標回溯，時間複雜度最差為 $O(n \times m)$。
- **KMP 演算法 (Knuth-Morris-Pratt)**：
  - 事先針對樣式字串計算**失敗函數（Failure Function $f(j)$）**。
  - 當遇到字元不相符時，利用已匹配的前綴資訊，將樣式字串向右滑動至最大共同前後綴處，**主字串指標絕不回溯**！
  - 時間複雜度大幅優化至 **$O(n + m)$**。
