## 1. 堆疊 (Stack)

### (1) 基本概念
- **LIFO (Last-In-First-Out，後進先出)**：最後放入的元素最先被取出。
- 所有插入（`Push`）與刪除（`Pop`）操作皆在同一端進行，該端稱為 **頂端 (Top)**，另一端稱為 **底端 (Bottom)**。

```mermaid
flowchart TD
    subgraph Stack [堆疊 (LIFO)]
        top["頂端 (Top) -> [ 元素 C ] (最後進，最先出)"]
        mid["[ 元素 B ]"]
        bot["底端 (Bottom) -> [ 元素 A ]"]
    end
```

### (2) 堆疊 ADT 與 C++ 範本宣告

```cpp
template <class T>
class Stack {
private:
    T *stack;
    int top;
    int capacity;
    void StackFull(); // 動態擴容 (通常倍增 capacity *= 2)
public:
    Stack(int stackCapacity = 10);
    bool IsEmpty() const { return top == -1; }
    T& Top() const;
    void Push(const T& item);
    void Pop();
};
```

### (3) 堆疊經典應用
1. **迷宮尋路 (Maze Problem / Backtracking)**：利用堆疊記錄探索過的路徑座標，遇到死巷時執行 `Pop` 退回上一路口。
2. **算式轉換與求值 (Expression Evaluation)**：
   - **中序表示式 (Infix)**：$A + B \times C$（人類習慣，需括號與優先順序）。
   - **後序表示式 (Postfix)**：$A B C \times +$（電腦最愛，無括號，由左至右掃描，遇到運算元 push，遇到運算子 pop 兩數運算後 push 回堆疊）。
   - **優先權設計**：
     - `isp` (in-stack priority)：堆疊內的優先權。
     - `icp` (in-coming priority)：即將進入堆疊的優先權（如左括號 `(` 在外最高，進堆疊後變最低）。

## 2. 佇列 (Queue)

### (1) 基本概念
- **FIFO (First-In-First-Out，先進先出)**：最先排入的元素最先被服務。
- 元素由一端排入，稱為 **後端 (Rear)**；元素由另一端取出，稱為 **前端 (Front)**。

### (2) 環狀佇列 (Circular Queue)

> [!WARNING] 線性佇列的「假滿 (False Overflow)」問題
> 線性佇列不斷進行 Add 與 Delete 後，`front` 與 `rear` 都會往後移動。當 `rear == capacity - 1` 時，即使陣列前面有多個空位，也無法再新增元素！
> **解決方案**：採用**環狀佇列（Circular Queue）**，將陣列視為首尾相接的環，透過取餘數（`% capacity`）循環利用空間。

#### 環狀佇列索引前進公式：
- 新增元素：`rear = (rear + 1) % capacity;`
- 刪除元素：`front = (front + 1) % capacity;`

#### 佇列狀態判定策略（保留一個空間）：
- **佇列為空 (Empty)**：`front == rear`
- **佇列已滿 (Full)**：`(rear + 1) % capacity == front`

## 3. C++ STL 容器對照

在實務或解題中，可直接引入 `<stack>` 與 `<queue>`：

| 容器 | 常用方法 |
|:---|:---|
| `std::stack<T>` | `push(x)`, `pop()`, `top()`, `empty()`, `size()` |
| `std::queue<T>` | `push(x)`, `pop()`, `front()`, `back()`, `empty()`, `size()` |
| `std::deque<T>` | 雙向佇列：`push_front()`, `push_back()`, `pop_front()`, `pop_back()` |
