## 1. 循序表示法 (Sequential) 之缺陷與鏈結串列

陣列雖然具備 $O(1)$ 隨機存取優點，但在資料動態維護上存在重大缺點：
1. **插入/刪除代價高**：在陣列中間插入或刪除元素，需要搬移後續所有元素，耗時 $O(n)$。
2. **容量大小固定**：編譯時期或執行初期宣告固定容量，過大浪費空間，過小導致溢位。

**鏈結串列 (Linked List)**：每個節點 (Node) 包含**資料欄位 (Data)** 與指向下一個節點的**指標欄位 (Link/Next)**，分散儲存於記憶體堆積區 (Heap)。

## 2. C++ 類別設計模式：複合類別與疊代器

溫敏淦老師 PPT 強調物件導向封裝設計：將節點 (`ChainNode`) 與串列容器 (`Chain`) 分離，並設計專屬疊代器 (`ChainIterator`)：

```cpp
template <class T> class Chain;         // 前向宣告
template <class T> class ChainIterator; // 疊代器前向宣告

template <class T>
class ChainNode {
    friend class Chain<T>;
    friend class ChainIterator<T>;
private:
    T data;
    ChainNode<T> *link;
public:
    ChainNode(const T& d = 0, ChainNode<T>* l = nullptr) : data(d), link(l) {}
};

template <class T>
class Chain {
private:
    ChainNode<T> *first; // 指向串列首節點
public:
    Chain() : first(nullptr) {}
    ~Chain();
    void InsertFront(const T& e);
    void InsertBack(const T& e);
    void Delete(const T& e);
    void Reverse();                     // 原地指標翻轉 O(n)
    void Concatenate(Chain<T>& b);      // 串接兩串列
};
```

## 3. 單向鏈結串列核心操作演算法

### 3.1 前端插入 (`InsertFront`) 與尾端插入 (`InsertBack`)
```cpp
template <class T>
void Chain<T>::InsertFront(const T& e) {
    first = new ChainNode<T>(e, first); // 新節點 link 指向原 first，並更新 first
}

template <class T>
void Chain<T>::InsertBack(const T& e) {
    ChainNode<T> *newNode = new ChainNode<T>(e, nullptr);
    if (!first) {
        first = newNode;
    } else {
        ChainNode<T> *curr = first;
        while (curr->link) curr = curr->link; // 走訪至尾端
        curr->link = newNode;
    }
}
```

### 3.2 串列反轉 (`Reverse`) —— 必考面試與期末題
在不配置新節點的情況下，利用三個指標將整條串列**原地逆轉 (In-place Reversal)**：

```cpp
template <class T>
void Chain<T>::Reverse() {
    ChainNode<T> *current = first;
    ChainNode<T> *previous = nullptr;
    while (current) {
        ChainNode<T> *r = previous; // r 暫存上一個節點
        previous = current;         // previous 前進至當前節點
        current = current->link;    // current 前進至下一個節點
        previous->link = r;         // 核心：將指標轉向指向前一個節點！
    }
    first = previous; // 更新串列首部
}
```
- **時間複雜度**：$O(n)$，**空間複雜度**：$O(1)$。

## 4. 環狀鏈結串列 (Circular List) 與可用空間池 (Free Pool)

### 4.1 環狀串列結構
串列最後一個節點的 link 不指向 `nullptr`，而是指向首節點 `first`（或首節點前置的 `Head Node`）。
- **優點**：從串列任何節點出發，皆可走訪整條串列所有節點；若維護 `last` 指標（指向尾端），則可以在 $O(1)$ 時間內同時完成 `InsertFront` 與 `InsertBack`！

---

### 4.2 記憶體管理與可用空間池 (Free Pool / Free Space List)
頻繁調用系統 `new` 與 `delete` 會造成記憶體碎裂並消耗 CPU。
- 溫敏淦老師 PPT 提出的解決方案：維護一條全局或類別靜態的**自由空間串列 (Free Pool, `av` 指標)**。
- 當刪除節點時，不將記憶體還給 OS，而是直接將該節點掛載入 `av` 串列前端 (`RetNode`)。
- 當需要新節點時，優先自 `av` 取出 (`GetNode`)，若 `av` 為空才調用系統 `new`。

```cpp
template <class T>
class CircularList {
private:
    ChainNode<T> *last;
    static ChainNode<T> *av; // 可用節點池開頭
public:
    ChainNode<T>* GetNode() {
        ChainNode<T> *node;
        if (av) {
            node = av;
            av = av->link; // 從 free pool 拔出
        } else {
            node = new ChainNode<T>();
        }
        return node;
    }

    void RetNode(ChainNode<T>* node) {
        node->link = av;
        av = node; // 歸還至 free pool 開頭
    }

    // 將整個環狀串列釋放回 Free Pool，只需 O(1) 時間！
    void Erase() {
        if (last) {
            ChainNode<T> *first = last->link;
            last->link = av;
            av = first;
            last = nullptr;
        }
    }
};
```

## 5. 多項式環狀串列相加 (Polynomial as Circular List)

在多項式相加時，若最後一個項相加為 0，處理一般鏈結串列往往需要很多邊界判斷。
- **Head Node 哨兵技巧**：
  - 串列前方加入一個標頭節點 (Head Node)。
  - 將標頭節點的指數設為 **`-1`**。
  - 當演算法走到 `-1` 時，代表已循環回到串列起點，判斷終止條件極為簡潔。

## 6. 稀疏矩陣之多重鏈結十字串列 (Orthogonal List / Multilist)

當稀疏矩陣進行頻繁的矩陣運算（如矩陣加法、乘法）時，三元組陣列表示法搬移資料過於昂貴。
- **十字鏈結串列 (Cross-Linked List / Orthogonal List)**：
  - 每個非零項節點包含：`row`, `col`, `value`, `down` (同一直行的下一個節點), `right` (同一水平列的下一個節點)。
  - 設有 $n$ 個列表頭與 $m$ 個行表頭，各自形成環狀串列。
  - 輸入矩陣並建構十字串列之時間複雜度為：$$O(\max\{rows, cols\} + terms)$$

## 7. 雙向環狀鏈結串列 (Doubly Linked Circular List)

單向串列無法由後往前搜尋，若要刪除特定節點 `ptr`，必須從頭遍歷找到其前驅節點 (Predecessor)。
- **雙向串列節點結構**：`llink` (左指標), `data`, `rlink` (右指標)。
- 加上首節點 (Head Node)，形成雙向環狀串列。

```text
    ┌───────┬──────┬───────┐
    │ llink │ data │ rlink │
    └───────┴──────┴───────┘
```

### 7.1 雙向環狀串列節點刪除演算法 (只需 $O(1)$)
```cpp
void DeleteNode(DoubleNode *x) {
    if (x == head) throw "Cannot delete head node!";
    x->llink->rlink = x->rlink;
    x->rlink->llink = x->llink;
    delete x;
}
```

### 7.2 雙向環狀串列節點插入演算法 (在節點 $p$ 右側插入新節點 $x$)
```cpp
void InsertRight(DoubleNode *p, DoubleNode *x) {
    x->llink = p;
    x->rlink = p->rlink;
    p->rlink->llink = x;
    p->rlink = x;
}
```

## 8. 廣義串列 (Generalized Lists)

> **定義**：廣義串列 $A$ 是一個由 $n \ge 0$ 個元素構成的有限序列：
> $$A = (\alpha_0, \alpha_1, \dots, \alpha_{n-1})$$
> 其中 $\alpha_i$ 可以是一個**單一原子元素 (Atom)**，也可以是**另一個廣義串列 (Sublist)**。

### 8.1 運算函數
- **`head(A)`**：廣義串列的第一個元素。
- **`tail(A)`**：拔除首元素後，其餘元素構成的廣義串列。

#### 範例：
- $B = (a, (b, c))$
  - $\text{head}(B) = a$
  - $\text{tail}(B) = ((b, c))$
  - $\text{head}(\text{tail}(B)) = (b, c)$
  - $\text{tail}(\text{tail}(B)) = ()$ (空串列)

### 8.2 廣義串列之遞迴演算法
- **求深度 (`Depth`)**：
  $$\text{Depth}(L) = \begin{cases} 0 & \text{若 } L \text{ 為空} \\ 1 + \max \{ \text{Depth}(x_i) \mid x_i \text{ 為子串列} \} & \text{其他情況} \end{cases}$$
- **共用串列與遞迴串列**：
  - 多個串列可共用相同的子串列以節省空間（需使用 `ref_count` 參照計數）。
  - 若串列包含自身（如 $D = (a, D)$），稱為遞迴串列，在釋放記憶體時若無特殊環狀偵測，會導致無窮迴圈。

## 9. 等價關係與等價類 (Equivalence Classes)

### 9.1 等價關係三大性質
對於集合 $S$ 上的關係 $\equiv$：
1. **反身性 (Reflexive)**：$x \equiv x$。
2. **對稱性 (Symmetric)**：$x \equiv y \iff y \equiv x$。
3. **遞移性 (Transitive)**：若 $x \equiv y$ 且 $y \equiv z$，則 $x \equiv z$。

### 9.2 求解等價類之鏈結演算法 (溫老師 PPT 流程)
- **階段一**：讀入等價對偶 $(i, j)$，建立無向圖之鄰接串列 (Adjacency List)。
- **階段二**：使用堆疊進行深度優先走訪 (DFS)，將所有相互連通的頂點輸出為同一個等價類，並標記已輸出節點。
- 時間複雜度：$O(m + n)$，其中 $m$ 為等價對數，$n$ 為元素總個數。
