## 1. 全科目核心演算法時間與空間複雜度終極對照表

| 資料結構 / 演算法 | 操作 / 情境 | 時間複雜度 (Time) | 額外空間 (Auxiliary Space) | 關鍵備註 |
| :--- | :--- | :---: | :---: | :--- |
| **二元搜尋 (Binary Search)** | 搜尋已排序陣列 | $O(\log n)$ | $O(1)$ (迭代) / $O(\log n)$ (遞迴) | 必備有序 |
| **稀疏矩陣直觀轉置** | 轉置矩陣 | $O(\text{terms} \cdot \text{cols})$ | $O(1)$ | 雙層迴圈掃描 |
| **稀疏矩陣快速轉置** | 轉置矩陣 | $\mathbf{O(\text{terms} + \text{cols})}$ | $O(\text{cols})$ | `rowTerms` + `startingPos` |
| **KMP 字串比對** | 樣式比對 | $\mathbf{O(m + n)}$ | $O(n)$ | 失敗函數 $f[j]$，文字指標不回退 |
| **環狀佇列** | Push / Pop | $O(1)$ | $O(1)$ | 留一空格法判斷滿空 |
| **迷宮回溯求解** | 尋找路徑 | $O(m \cdot p)$ | $O(m \cdot p)$ | 8 方向 Offset + Stack |
| **中序轉後序** | 算式轉換 | $O(n)$ | $O(n)$ | 雙優先權表 `isp`/`icp` |
| **鏈結串列原地反轉** | 指標反轉 | $O(n)$ | $\mathbf{O(1)}$ | 三指標動態更換 |
| **二元樹走訪** | In/Pre/Post/Level | $O(n)$ | $O(h)$ (Stack) / $O(w)$ (Queue) | $h$: 樹高, $w$: 樹寬 |
| **引線二元樹走訪** | Inorder 遍歷 | $O(n)$ | $\mathbf{O(1)}$ | 空指標利用，完全免 Stack |
| **Max/Min Heap** | 插入 / 刪除 | $O(\log n)$ | $O(1)$ | Percolate Up / Down |
| **二元搜尋樹 (BST)** | 搜尋 / 插入 / 刪除 | $O(h)$ (平均 $O(\log n)$) | $O(h)$ | 最壞退化為 $O(n)$ |
| **Disjoint Sets (並查集)** | $m$ 次操作 | $\mathbf{O(m \cdot \alpha(m, n))}$ | $O(n)$ | Weighted Union + Collapsing Find |
| **DFS / BFS** | 圖走訪 | 串列 $O(n+e)$ / 矩陣 $O(n^2)$ | $O(n)$ | Stack / Queue |
| **Kruskal (MST)** | 最小生成樹 | $\mathbf{O(e \log e)}$ | $O(e)$ | 邊排序 + Union-Find |
| **Prim (MST)** | 最小生成樹 | 矩陣 $O(n^2)$ / 堆積 $O(e \log n)$ | $O(n)$ | 從點擴展 |
| **Dijkstra** | 單源最短路徑 | $O(n^2)$ | $O(n)$ | 不可有負邊 |
| **Bellman-Ford** | 單源最短路徑 | $\mathbf{O(n \cdot e)}$ | $O(n)$ | 可有負邊，可偵測負權環 |
| **Floyd-Warshall** | 全點對最短路徑 | $\mathbf{O(n^3)}$ | $O(n^2)$ | 動態規劃三重迴圈 |
| **拓撲排序 (Topological)** | AOV 網路排程 | $O(n + e)$ | $O(n)$ | 入度為 0 入棧，偵測 Directed Cycle |
| **關鍵路徑 (AOE CPM)** | 最長完工工期 | $O(n + e)$ | $O(n + e)$ | $ee, le, e, l$，寬裕時間為 0 |
| **插入排序 (Insertion)** | 內部排序 | 最佳 $O(n)$ / 最差 $O(n^2)$ | $O(1)$ | 穩定，逆序數 $O(n+k)$ |
| **快速排序 (Quick)** | 內部排序 | 平均 $O(n \log n)$ / 最差 $O(n^2)$ | $O(\log n)$ | 不穩定，三數中值法 |
| **合併排序 (Merge)** | 內部排序 | 恆為 $\mathbf{O(n \log n)}$ | $O(n)$ | 穩定 |
| **堆積排序 (Heap)** | 內部排序 | 恆為 $\mathbf{O(n \log n)}$ | $\mathbf{O(1)}$ | 不穩定，原地排序 |
| **基數排序 (Radix)** | 內部排序 | $O(d(n + r))$ | $O(r)$ | 穩定，非比較型 |
| **雜湊表 (Separate Chaining)** | 搜尋 / 插入 / 刪除 | 平均 $O(1)$ / 最差 $O(n)$ | $O(n)$ | 避免 Primary Clustering |

## 2. 期末考必考手算與推導題型清單

1. **二元樹葉節點證明**：
   $$n = n_0 + n_1 + n_2, \quad B = n - 1 = n_1 + 2n_2 \implies \mathbf{n_0 = n_2 + 1}$$
2. **比較式排序理論下限證明**：
   決策樹葉節點 $\ge n! \implies h \ge \log_2(n!) + 1 \implies \mathbf{\Omega(n \log n)}$。
3. **KMP 失敗函數手算**：
   給定字串樣式，求最長真前後綴相等長度 $f[j]$。
4. **中序轉後序雙優先權表**：
   左括號 `(` 在外 $icp=20$ 最高、在內 $isp=0$ 最低。
5. **快速轉置手算**：
   計算 `rowTerms` 與 `startingPos`。
6. **AOE 關鍵路徑四部曲**：
   前向推 $ee$，後向推 $le$，算活動 $e$ 與 $l$，找出 $l - e == 0$。
7. **關節點判定**：
   DFS 樹根節點小孩數 $\ge 2$；非根節點存在小孩 $low[v] \ge dfn[u]$。
