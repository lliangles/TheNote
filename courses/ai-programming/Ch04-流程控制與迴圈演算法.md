## 📌 1. 條件判斷式 (if-elif-else)

```python
# ==============================================================================
# 範例程式 4-1：多向條件判斷與三元運算子
# ==============================================================================

score = 88

# 1. 多向分支結構
if score >= 90:
    grade = "A+"
elif score >= 80:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "F"

print(f"分數: {score} -> 等第: {grade}")

# 2. Python 三元運算子 (Ternary Operator / 條件運算式)
# 語法: [真值結果] if [條件] else [假值結果]
status = "及格 PASS" if score >= 60 else "不及格 FAIL"
print(f"判定狀態: {status}")
```

## 📌 2. 迴圈結構：for 與 while

### 1. `range()` 數列產生器
語法：`range(start, stop, step)`，產生由 `start` 開始、小於 `stop`、間隔為 `step` 的整數迭代器。

```python
# ==============================================================================
# 範例程式 4-2：for 迴圈結合 enumerate 與 zip 迭代
# ==============================================================================

students = ["小明", "小華", "小美"]
math_scores = [92, 85, 78]
eng_scores = [88, 90, 95]

# 技巧 1：enumerate() 同時取得「索引序號」與「元素值」
print("--- 學生清單編號 ---")
for idx, name in enumerate(students, start=1):
    print(f"序號 {idx:02d}: {name}")

# 技巧 2：zip() 將多個串列打包並行走訪
print("\n--- 多科成績整合 ---")
for name, m, e in zip(students, math_scores, eng_scores):
    avg = (m + e) / 2
    print(f"學生: {name} | 數學: {m} | 英文: {e} | 平均: {avg:.1f}")
```

## 📌 3. 課堂演練演算法：倍數搜尋與累計總和

在 `Untitled-1.ipynb` 筆記中，溫敏淦教授特別設計了「搜尋 1 到 n 之間所有特定倍數並計算其總和」之演算法題：

```python
# ==============================================================================
# 範例程式 4-3：1 到 n 範圍內特定倍數篩選與累加演算法
# 說明：對應溫敏淦教授課堂作業練習
# ==============================================================================

def find_multiples_and_sum(n: int, target: int = 3):
    """
    找出 1 到 n 範圍內所有 target 的倍數，並計算其總和
    :param n: 上界整數
    :param target: 目標倍數因子（預設為 3）
    :return: (倍數串列, 總和)
    """
    multiples = []      # 儲存符合條件的倍數
    total_sum = 0       # 累加總和

    for number in range(1, n + 1):
        # 使用餘數運算子 % 判斷是否整除
        if number % target == 0:
            multiples.append(number)
            total_sum += number

    return multiples, total_sum

# 實測執行：以 n = 30, target = 3 為例
n_limit = 30
result_list, result_sum = find_multiples_and_sum(n_limit, 3)

print(f"=== 1 到 {n_limit} 之間 3 的倍數演練 ===")
print(f"符合的數值串列: {result_list}")
print(f"倍數總個數:     {len(result_list)} 個")
print(f"倍數加總總和:   {result_sum}")
```

## 📌 4. 迴圈進階控制：break、continue 與 else 子句

Python 具有其他語言少見的**迴圈 `else` 子句**：
- 當迴圈**正常執行完畢（沒有被 `break` 強制中斷）**時，才會執行 `else` 區塊。
- 常用於**搜尋判斷（搜尋完全部都沒找到目標時觸發）**。

```python
# ==============================================================================
# 範例程式 4-4：質數判定演算法與迴圈 else 子句
# ==============================================================================

def check_prime(num: int):
    """判斷一整數是否為質數"""
    if num <= 1:
        return False

    for factor in range(2, int(num ** 0.5) + 1):
        if num % factor == 0:
            print(f"{num} 不是質數（可被 {factor} 整除）")
            break  # 找到因數，立即終止迴圈
    else:
        # 迴圈完全跑完沒有遇到 break，表示完全無其他因數！
        print(f"🎉 {num} 是質數 (Prime Number)！")

check_prime(29)   # 是質數
check_prime(35)   # 不是質數 (5 * 7)
```
