## 📌 1. 四大內建資料結構特性對比表

| 特性比較 | 串列 (List) | 元組 (Tuple) | 字典 (Dictionary) | 集合 (Set) |
| :--- | :---: | :---: | :---: | :---: |
| **宣告符號** | `[1, 2, 3]` | `(1, 2, 3)` | `{"key": "value"}` | `{1, 2, 3}` |
| **可否修改 (Mutable)** | **可修改 (Mutable)** | **不可修改 (Immutable)** | **可修改 (Mutable)** | **可修改 (Mutable)** |
| **順序性 (Ordered)** | 保留插入順序 | 保留插入順序 | 保留插入順序 (3.7+) | **無序 (Unordered)** |
| **重複元素 (Duplicates)** | 允許重複 | 允許重複 | 鍵 (Key) 唯一，值可重複 | **元素唯一（自動去重）** |
| **元素存取方式** | 整數索引 `list[0]` | 整數索引 `tuple[0]` | 鍵存取 `dict["key"]` | 無索引，使用 `in` 判斷 |

## 📌 2. 串列 (List) 切片、增刪與切片賦值

```python
# ==============================================================================
# 範例程式 3-1：串列基礎、切片與切片賦值（對應課堂實作 Untitled-1.ipynb）
# ==============================================================================

# 1. 建立串列與二維巢狀串列
grades = [85, 92, 78, 65, 99]
matrix = [[1, 2], [3, 4]]              # 二維陣列結構

# 2. 常用操作方法
grades.append(88)                      # 在尾端加入元素
grades.insert(1, 100)                  # 在指定索引 1 插入元素 100
removed_item = grades.pop()            # 彈出並移除最後一個元素
print(f"移除最後元素: {removed_item}, 當前串列: {grades}")

# 3. 切片語法: list[start:stop:step]（含 start，不含 stop）
sub_list = grades[1:4]                 # 取索引 1, 2, 3
reverse_list = grades[::-1]            # 步長 -1 代表反轉整個串列
print(f"切片子串列 [1:4]: {sub_list}")
print(f"反轉串列: {reverse_list}")

# 4. 課堂重點：切片賦值 (Slicing Assignment)
# 可以直接用新串列替換指定區間的元素，甚至長度可以不相等！
a = [0, 1, 2, 3, 4]
a[1:3] = [8, 9]                        # 將原本索引 1 與 2 (值 1, 2) 替換為 [8, 9]
print(f"切片賦值替換後: {a}")           # 輸出: [0, 8, 9, 3, 4]

a[1:3] = [999]                         # 長度不相等亦可替換，縮短串列
print(f"不同長度切片賦值後: {a}")       # 輸出: [0, 999, 3, 4]
```

## 📌 3. 串列表達式 (List Comprehension)

串列表達式為 Pythonic 最具代表性的語法糖，比傳統 `for` 迴圈更簡潔且執行速度更快：

```python
# ==============================================================================
# 範例程式 3-2：串列表達式與條件過濾
# ==============================================================================

# 範例：計算 1 到 10 的平方值
# 傳統做法：
squares_old = []
for x in range(1, 11):
    squares_old.append(x ** 2)

# List Comprehension 做法：
squares_new = [x ** 2 for x in range(1, 11)]
print(f"1~10 平方: {squares_new}")

# 加上條件過濾 (if)：只取偶數的平方
even_squares = [x ** 2 for x in range(1, 11) if x % 2 == 0]
print(f"1~10 偶數平方: {even_squares}")  # [4, 16, 36, 64, 100]
```

## 📌 4. 字典 (Dictionary) 與 集合 (Set)

```python
# ==============================================================================
# 範例程式 3-3：字典鍵值映射與集合交聯運算
# ==============================================================================

# 1. 字典 (Key-Value Map)
student_info = {
    "name": "張小明",
    "id": "A112001",
    "scores": {"AI": 95, "DataStructure": 88},
    "is_enrolled": True
}

# 推薦使用 get() 取值：若鍵不存在回傳預設值 None，防止引發 KeyError 崩潰
print(f"學生姓名: {student_info.get('name')}")
print(f"修習統計學: {student_info.get('Statistics', '尚未選課')}")

# 遍歷字典中的 Key 與 Value
for subject, score in student_info["scores"].items():
    print(f"  科目: {subject} -> 得分: {score}")

# 2. 集合 (Set)：自動剔除重複元素與數學集合運算
club_a = {"小明", "小華", "小虹", "阿強"}
club_b = {"小明", "小華", "小莉", "大雄"}

# 集合運算
both_clubs = club_a & club_b          # 交集 (Intersection)
all_members = club_a | club_b         # 聯集 (Union)
only_in_a = club_a - club_b           # 差集 (Difference)

print(f"同時參加兩社團: {both_clubs}")
print(f"全體不重複名冊: {all_members}")
print(f"僅參加 A 社團: {only_in_a}")
```

## 📌 5. 記憶體參照：淺拷貝 (Shallow Copy) vs 深拷貝 (Deep Copy)

在 Python 中，變數名稱本質上是**指向記憶體物件的指針（參照 Reference）**。若未了解拷貝機制，修改子串列將引發嚴重的非預期錯誤：

```python
# ==============================================================================
# 範例程式 3-4：淺拷貝 vs 深拷貝深度比較
# ==============================================================================
import copy

original = [[1, 2, 3], [4, 5, 6]]

# 1. 直接指派（Reference）：完全同一物件
ref_assign = original

# 2. 淺拷貝（Shallow Copy）：複製外層串列，但內層巢狀子物件仍然共享參照
shallow_copy = original.copy()        # 或 copy.copy(original)

# 3. 深拷貝（Deep Copy）：遞迴完整複製所有層級的物件，完全獨立於記憶體
deep_copy = copy.deepcopy(original)

# 修改原始串列的內層元素
original[0][0] = 999

print(f"原始串列:   {original}")       # [[999, 2, 3], [4, 5, 6]]
print(f"直接指派:   {ref_assign}")     # [[999, 2, 3], [4, 5, 6]] (連動被改)
print(f"淺拷貝結果: {shallow_copy}")   # [[999, 2, 3], [4, 5, 6]] (內層共享，連動被改！)
print(f"深拷貝結果: {deep_copy}")      # [[1, 2, 3], [4, 5, 6]]   (完全獨立，不受影響！)
```
