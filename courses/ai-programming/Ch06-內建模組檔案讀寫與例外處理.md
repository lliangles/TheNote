## 📌 1. 物件導向程式設計核心 (OOP in Python)

> [!IMPORTANT] 簡報第 1~10 頁核心架構
> Python 中「一切皆物件 (Everything is an object)」。類別 (Class) 是產生物件的藍圖，而物件 (Object / Instance) 是實際佔用記憶體的實體。

### 1-1. 類別定義、`self` 與初始化函式
* **`self` 的本質**：成員方法的第一個參數必須是 `self`，代表**呼叫該方法的實例物件本身**（類似 C++ / Java 中的 `this` 指針）。在外部呼叫 `obj.method()` 時，Python 會自動將 `obj` 作為第一引數傳入，因此外部呼叫時不需傳遞 `self`。
* **`__init__(self, ...)`**：物件的初始化建構函式，在物件建立後自動觸發，用以初始化實例屬性。

```python
class Student:
    # 類別成員變數 (Class Attribute)：所有實例物件共用同一份記憶體
    school_name = "國立聯合大學"

    def __init__(self, student_id: str, name: str):
        # 物件成員變數 (Instance Attribute)：每個物件獨立擁有
        self.student_id = student_id
        self.name = name

    def display(self):
        """實例方法 (Instance Method)"""
        return f"[{self.school_name}] 學號: {self.student_id} | 姓名: {self.name}"
```

### 1-2. 私有成員變數與名稱改寫 (Name Mangling)
* **語法**：在變數或方法名稱前加上**雙底線前綴 `__`**（且結尾不可為雙底線），即被宣告為**私有成員 (Private)**。
* **保護機制**：直譯器會自動進行名稱改寫 (Name Mangling)，將 `__balance` 改名為 `_類別名__balance`，防止外部直接存取或子類別意外覆蓋。
```python
class BankAccount:
    def __init__(self, owner: str, initial_balance: float):
        self.owner = owner
        self.__balance = initial_balance  # 私有成員變數

    def deposit(self, amount: float):
        if amount > 0:
            self.__balance += amount

    def get_balance(self) -> float:
        """透過公開方法存取私有變數 (Getter)"""
        return self.__balance

account = BankAccount("張小明", 1000)
# print(account.__balance)        # ❌ 拋出 AttributeError: 'BankAccount' object has no attribute '__balance'
print(f"餘額: {account.get_balance()}") # ✅ 正確存取: 1000
```

### 1-3. 繼承 (Inheritance)、`super()` 與遮蔽效應 (Override)
* Python 支援**單一繼承**、**鏈狀繼承**與**多重繼承**。所有未特別指定父類別的類別，預設皆繼承自根類別 **`object`**。
* **方法遮蔽 (Override)**：子類別若定義了與父類別同名的方法，會優先使用子類別的方法。
* **`super()`**：用於在子類別中主動呼叫父類別被遮蔽的方法或初始化建構函式。
* **型別判定**：
  * `isinstance(obj, ClassName)`：檢查物件是否為該類別（或其衍生子類別）的實例。
  * `issubclass(SubClass, SuperClass)`：檢查兩類別是否存在繼承關係。

```python
# ==============================================================================
# 範例程式 6-1：繼承、super() 與型別檢驗
# ==============================================================================
class AIModel:
    """父類別：AI 基礎模型"""
    def __init__(self, model_name: str):
        self.model_name = model_name

    def train(self, data):
        return f"正在訓練通用模型: {self.model_name}"

class NeuralNetwork(AIModel):
    """子類別：神經網路"""
    def __init__(self, model_name: str, layers: list[int]):
        super().__init__(model_name)  # 呼叫父類別建構函式
        self.layers = layers

    def train(self, data):
        # 覆寫 (Override) 父類別方法
        parent_msg = super().train(data)
        return f"{parent_msg} -> 採用多層神經架構: {self.layers}"

nn = NeuralNetwork("DNN-V1", [784, 128, 10])
print(nn.train("MNIST"))
print(f"nn 是否屬於 AIModel 類別實例: {isinstance(nn, AIModel)}")      # True
print(f"NeuralNetwork 是否為 AIModel 子類: {issubclass(NeuralNetwork, AIModel)}") # True
```

### 1-4. 類別方法 (`@classmethod`) 與靜態方法 (`@staticmethod`)
* **`@classmethod`**：首個參數固定為 `cls`（代表類別本身），常用於編寫替代工廠建構函式。
* **`@staticmethod`**：不需要 `self` 也不需要 `cls`，與一般獨立函式無異，僅在邏輯上歸屬於該類別命名空間。

## 📌 2. 模組 (Module) 與套件 (Package) 架構機制

> [!IMPORTANT] 簡報第 17~29 頁模組化規範
> * **模組 (Module)**：單一獨立的 Python 檔案（副檔名 `.py`）。
> * **套件 (Package)**：包含子模組的**目錄資料夾**，且目錄內必須包含 **`__init__.py`** 檔案。

### 2-1. `__init__.py` 的關鍵陷阱
* 當執行 `import my_pkg` 時，**直譯器實際上僅會載入該套件底下的 `__init__.py` 模組**，並不會自動匯入該資料夾內的其他子模組！
* 若要使用子模組 `mdp.py`，必須顯式宣告：
  ```python
  import my_pkg.mdp
  # 或
  from my_pkg import mdp
  ```

### 2-2. 命名遮蔽與 `as` 別名保護
* 當多個模組包含相同名稱的變數或函式時（例如 `module_a.fun` 與 `module_b.fun`），若以 `from module_a import fun` 與 `from module_b import fun` 同時匯入，**後者會無情地覆蓋前者（名稱標籤原則）**！
* **防護對策**：使用 `as` 關鍵字賦予別名，徹底消除衝突：
  ```python
  from module_a import fun as fun_a
  from module_b import fun as fun_b
  ```

### 2-3. `__name__ == '__main__'` 執行期主程式判定
```python
# 模組自我測試與被匯入防護標準樣板
def main():
    print("作為主程式獨立執行")

if __name__ == "__main__":
    # 當直接執行 python my_script.py 時，__name__ 為 "__main__"
    main()
else:
    # 當被其他模組 import my_script 時，__name__ 為 "my_script"，此區塊不執行
    pass
```

## 📌 3. 正規表達式 `re` 模組語法 (Regular Expressions)

正規表達式是文字搜尋與爬蟲網頁萃取的利器：

| 語法符號 | 意義說明 | 範例與比對結果 |
|:---:|:---|:---|
| `\d` | 單一數字（等價於 `[0-9]`） | `\d+` 匹配連續整數 |
| `\w` | 單一英數字或底線 | `\w+` 匹配變數識別碼 |
| `\s` | 空白、Tab 或換行 | `\s*` 匹配任意空格 |
| `.` | 任意單一字元（換行除外） | `a.c` 匹配 "abc", "a9c" |
| `^` / `$` | 字串開頭 / 字串結尾 | `^\d{4}$` 匹配精確 4 位數年份 |
| `*` / `+` / `?` | 重複 0 次以上 / 1 次以上 / 0 或 1 次 | `https?` 匹配 http 或 https |
| `[a-z]` | 字元集合（範圍選擇） | `[A-Z]` 匹配單一大寫字母 |

### 常用函式比較：`re.match()` vs `re.search()` vs `re.sub()`
* **`re.match()`**：**僅從字串的「第 0 個字元」開始比對**，若開頭不符合直接傳回 `None`。
* **`re.search()`**：**掃描整個字串**，找出第一個符合的子字串（推薦）。
* **`re.findall()`**：找出字串中**所有**符合的子字串並以串列傳回。
* **`re.sub(pattern, repl, string)`**：將找到的子字串置換為指定文字。
* **`re.compile(pattern)`**：將樣式預編譯為 Regex 物件，大幅提升百萬次重複搜尋之效能。

```python
# ==============================================================================
# 範例程式 6-2：re 模組萃取與預編譯
# ==============================================================================
import re

text = "聯絡電話: 0912-345678, 備用電話: 0988-765432, 郵件: ai@nuu.edu.tw"

# 1. 預編譯手機格式: 09xx-xxxxxx
phone_pattern = re.compile(r"09\d{2}-\d{6}")
phones = phone_pattern.findall(text)
print(f"抓取所有手機號碼: {phones}") # ['0912-345678', '0988-765432']

# 2. sub 脫敏替換
masked_text = phone_pattern.sub("09XX-XXXXXX", text)
print(f"個資脫敏後內容: {masked_text}")
```

## 📌 4. 檔案讀寫與 Context Manager (`with` 語法)

### 4-1. `with open(...)` 自動關閉保證
在進行檔案 I/O 操作時，嚴格遵守使用 `with` 語法：
* 無論檔案讀取是否成功，或內部是否觸發例外中斷，**作業系統檔案控制代碼 (File Descriptor) 保證自動關閉**，防止記憶體洩漏與磁碟鎖死。
* **編碼鐵律**：讀寫繁體中文檔案時，**務必顯式宣告 `encoding="utf-8"`**，防止 Windows 預設 `cp950` 編碼引發 `UnicodeDecodeError`。

```python
# ==============================================================================
# 範例程式 6-3：純文字、CSV 與 JSON 安全讀寫
# ==============================================================================
import json
import csv
import os

os.makedirs("temp_io", exist_ok=True)
json_path = "temp_io/config.json"
csv_path  = "temp_io/scores.csv"

# 1. JSON 讀寫 (ensure_ascii=False 確保中文字不轉為 unicode 碼)
config_data = {"course": "人工智慧概論", "credits": 3, "tags": ["Python", "AI", "ML"]}
with open(json_path, "w", encoding="utf-8") as f:
    json.dump(config_data, f, ensure_ascii=False, indent=2)

with open(json_path, "r", encoding="utf-8") as f:
    loaded_config = json.load(f)
print(f"成功讀取 JSON 課程名: {loaded_config['course']}")

# 2. CSV 讀寫 (newline='' 防止 Windows 平台寫入多餘空行)
data_rows = [
    ["學號", "姓名", "成績"],
    ["112001", "張小明", 95],
    ["112002", "李小華", 88]
]
with open(csv_path, "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data_rows)

# 清理測試檔案
os.remove(json_path)
os.remove(csv_path)
os.rmdir("temp_io")
```
