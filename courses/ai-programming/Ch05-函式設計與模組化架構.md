## 📌 1. 函式定義、引數與預設值

函式 (Function) 是將重複使用的程式邏輯打包成獨立模組的核心單元，遵循 **DRY (Don't Repeat Yourself)** 原則。

```python
# ==============================================================================
# 範例程式 5-1：函式定義、型別提示 (Type Hints) 與回傳多值
# ==============================================================================

def calculate_stats(scores: list[float]) -> tuple[float, float, float]:
    """
    計算成績清單的總分、平均值與最高分
    :param scores: 浮點數成績串列
    :return: (總分, 平均分, 最高分) 的元組
    """
    if not scores:
        return 0.0, 0.0, 0.0

    total = sum(scores)
    average = total / len(scores)
    highest = max(scores)

    # Python 支援直接回傳多個數值，本質上是打包成一個 Tuple
    return total, average, highest

# 呼叫函式並透過元組拆包 (Unpacking) 接收回傳值
my_scores = [85.5, 92.0, 78.5, 96.0, 60.5]
tot, avg, high = calculate_stats(my_scores)

print(f"總分: {tot} | 平均分: {avg:.2f} | 最高分: {high}")
```

> [!CAUTION]
> ### ⚠️ 經典陷阱：切勿使用「可變物件 (Mutable)」作為預設參數！
> 若使用空串列 `def append_item(x, lst=[])`，該預設串列會在記憶體中被所有後續呼叫**持續共享**！  
> **正確做法**：預設值設為 `None`，並在函式內部檢查初始化：
> ```python
> def safe_append(item, target_list=None):
>     if target_list is None:
>         target_list = []
>     target_list.append(item)
>     return target_list
> ```

## 📌 2. 不定長度參數：`*args` 與 `**kwargs`

- `*args`：接收任意數量的**位置引數**，在函式內部打包為一個 **元組 (Tuple)**。
- `**kwargs`：接收任意數量的**關鍵字引數**，在函式內部打包為一個 **字典 (Dictionary)**。

```python
# ==============================================================================
# 範例程式 5-2：通用模型配置器（展示 *args 與 **kwargs 解包）
# ==============================================================================

def configure_ai_model(model_name: str, *features, **hyperparameters):
    """
    配置 AI 模型的彈性函式
    :param model_name: 模型架構名稱
    :param features: 欲使用的特徵欄位 (*args)
    :param hyperparameters: 超參數鍵值對 (**kwargs)
    """
    print(f"=== 配置模型: {model_name} ===")
    print(f"1. 納入訓練特徵 ({len(features)} 項):")
    for f in features:
        print(f"   - {f}")

    print("2. 超參數設定:")
    for param, value in hyperparameters.items():
        print(f"   - {param}: {value}")

# 呼叫示範
configure_ai_model(
    "XGBoost Classifier",
    "收盤價", "成交量", "RSI指標", "MACD柱狀圖",      # 傳入 *args
    learning_rate=0.05, n_estimators=200, max_depth=6  # 傳入 **kwargs
)
```

## 📌 3. 變數作用域 (Scope) 與 LEGB 規則

Python 查找變數的順序為 **LEGB**：
1. **L (Local)**：當前函式內部。
2. **E (Enclosing)**：外部嵌套函式（閉包環境）。
3. **G (Global)**：模組最外層的全域變數。
4. **B (Built-in)**：Python 內建函式庫（如 `len`, `sum`, `print`）。

- 若要在函式內部修改全域變數，必須顯式宣告 `global 變數名稱`。

## 📌 4. 匿名函式 (Lambda) 與高階函式 (Map / Filter)

匿名函式語法：`lambda 參數1, 參數2: 運算表達式`

```python
# ==============================================================================
# 範例程式 5-3：Lambda 結合 map()、filter() 與自訂排序
# ==============================================================================

# 1. 基礎 Lambda
square = lambda x: x ** 2
print(f"Lambda 計算 8 的平方: {square(8)}")

# 2. map()：對串列中每個元素套用相同運算
celsius_temps = [0, 20, 25, 30, 37.5]
# 攝氏轉華氏公式: F = C * 1.8 + 32
fahrenheit_temps = list(map(lambda c: c * 1.8 + 32, celsius_temps))
print(f"華氏溫度轉換結果: {fahrenheit_temps}")

# 3. filter()：篩選符合特定條件的元素
nums = [12, 45, 68, 23, 89, 90, 33, 102]
over_50 = list(filter(lambda x: x > 50, nums))
print(f"大於 50 的數值: {over_50}")

# 4. 字典串列自訂多鍵排序
students = [
    {"name": "小明", "score": 85},
    {"name": "小華", "score": 92},
    {"name": "小美", "score": 78}
]
# 依成績由高至低排序 (reverse=True)
students_sorted = sorted(students, key=lambda s: s["score"], reverse=True)
print(f"成績由高至低排名: {students_sorted}")
```
