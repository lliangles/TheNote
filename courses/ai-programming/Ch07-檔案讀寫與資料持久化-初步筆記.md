## 1. 上下文管理器與編碼規範
永遠使用 `with open` 確保檔案 handle 自動安全關閉，並指定 `encoding='utf-8'` 防止 Windows CP950 亂碼：
```python
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("人工智慧資料集\n")
```

## 2. JSON 與 CSV 資料交換
```python
import json

data = {"model": "Gemini-1.5-Pro", "accuracy": 0.945, "parameters": 175000000}
with open("metadata.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=4)
```
