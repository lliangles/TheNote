## 1. 正規表示式核心語法速查
```python
import re

text = "Contact: info@nuu.edu.tw or admin@test.com.tw. Call: 037-381514."

# 擷取電子郵件
emails = re.findall(r'[\w\.-]+@[\w\.-]+', text)
print(emails)  # ['info@nuu.edu.tw', 'admin@test.com.tw']

# 擷取電話號碼
phone = re.search(r'\d{3}-\d{6}', text).group()
print(phone)   # '037-381514'
```
