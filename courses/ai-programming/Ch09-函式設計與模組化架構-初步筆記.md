## 1. 彈性參數與 Type Hints
```python
def train_model(model_name: str, *features: str, learning_rate: float = 0.001, **hyperparams) -> dict:
    print(f"Training {model_name} with features: {features}")
    print(f"Hyperparameters: {hyperparams}")
    return {"status": "trained", "lr": learning_rate}

train_model("CNN", "pixel_val", "edge", epochs=50, batch_size=32)
```
