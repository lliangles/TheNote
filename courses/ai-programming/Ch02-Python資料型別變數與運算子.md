## 📌 1. 變數與基本資料型別

Python 為**動態強型別語言 (Dynamically and Strongly Typed)**：
- **動態**：變數無需事先宣告型別，賦值時直譯器自動推論。
- **強型別**：不同型別之間不會隨意隱式轉換（例如 `'5' + 5` 會拋出 `TypeError`，必須顯式轉換）。

```python
# ==============================================================================
# 範例程式 2-1：變數賦值與型別動態偵測
# ==============================================================================

# 1. 整數 (int) 與 浮點數 (float)
student_id = 112001               # 整數
exam_score = 92.5                 # 浮點數

# 2. 布林值 (bool)：只有 True 與 False（字首必須大寫）
is_passed = exam_score >= 60      # True

# 3. 字串 (str)：支援單引號、雙引號或三引號（多行文字）
course_name = "人工智慧程式設計"
multi_line_text = """
國立聯合大學 資訊管理學系
授課教師：溫敏淦 教授
"""

# 使用 type() 函數印出型別
print(f"student_id 型別: {type(student_id)}")      # <class 'int'>
print(f"exam_score 型別: {type(exam_score)}")      # <class 'float'>
print(f"is_passed  型別: {type(is_passed)}")       # <class 'bool'>
print(f"course_name型別: {type(course_name)}")      # <class 'str'>
```

## 📌 2. 算術、比較與邏輯運算子

| 運算子類別 | 符號 | 說明與範例 | 注意事項 |
| :--- | :---: | :--- | :--- |
| **算術運算子** | `+`, `-`, `*` | 加、減、乘 | `5 * 2 = 10` |
| | `/` | **真除法（結果必為浮點數 float）** | `7 / 2 = 3.5` |
| | `//` | **整數除法（無條件捨去小數點）** | `7 // 2 = 3` |
| | `%` | **求餘數（Modulus）** | `7 % 2 = 1`（常用於判斷奇偶數或週期） |
| | `**` | **次方運算（Power）** | `2 ** 3 = 8` |
| **比較運算子** | `==`, `!=` | 等於、不等於 | 回傳布林值 `True` 或 `False` |
| | `>`, `<`, `>=`, `<=`| 大於、小於、大於等於、小於等於 | 支援連續比較：`18 <= age <= 65` |
| **邏輯運算子** | `and` | 邏輯與（兩者皆真才為真） | 具備短路求值 (Short-circuit) |
| | `or` | 邏輯或（任一為真即為真） | 具備短路求值 |
| | `not` | 邏輯非（反轉布林值） | `not True` 為 `False` |

```python
# ==============================================================================
# 範例程式 2-2：運算子實作與連續比較
# ==============================================================================

num = 17

# 整數除法 vs 餘數
quotient = num // 5    # 3
remainder = num % 5    # 2
power_val = 2 ** 10    # 1024

print(f"17 除以 5 的商數 = {quotient}, 餘數 = {remainder}")
print(f"2 的 10 次方 = {power_val}")

# 邏輯連續比較 (Chained Comparison)
score = 85
is_good = 80 <= score <= 90  # Python 支援數學連續不等式寫法
print(f"成績 85 是否在 80~90 之間: {is_good}")
```

## 📌 3. 字串操作與格式化輸出 (f-string)

```python
# ==============================================================================
# 範例程式 2-3：字串進階操作與格式化美化輸出
# ==============================================================================

name = "溫敏淦"
title = "教授"
subject = "AI 程式設計"
gpa = 3.87654

# 1. 傳統字串拼接 (不推薦，效率差且易報錯)
msg_old = name + " " + title + " 開設 " + subject

# 2. 現代 Python 首選：f-string (Python 3.6+)
# 支援變數嵌入、運算式直接計算、數值精度控制與對齊
print(f"【課程公告】{name}{title} 開啟《{subject}》課堂！")

# 格式化數值輸出：控制小數點位數
print(f"平均 GPA: {gpa:.2f}")           # 輸出: 3.88 (四捨五入至小數後兩位)

# 補零與對齊
for i in range(1, 4):
    print(f"學號編號: {i:04d} 號同學")   # 輸出: 0001, 0002, 0003

# 字串常用內建方法
raw_data = "   artificial intelligence, machine learning, deep learning   "
cleaned = raw_data.strip()             # 去除頭尾空白
topics = cleaned.split(", ")           # 依照逗號分割成串列
joined_str = " | ".join(topics)        # 用分隔線重新串接

print(f"處理後文字: {joined_str}")
```
