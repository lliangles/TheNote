## 2. 期末考必考計算與推導清單

1. **ER 轉換關聯表格**：多對多 (M:N) 必須自立新表並結合兩方主鍵；弱實體必須引入主實體之主鍵作為外鍵並共同組成主鍵。
2. **正規化逐步分解**：計算屬性閉包 (Attribute Closure $X^+$)，找出候選鍵，證明是否滿足 3NF / BCNF。
3. **優先圖畫圖題**：檢查衝突操作 $R(x)-W(x), W(x)-R(x), W(x)-W(x)$，連線後判別圖是否有環。
4. **崩潰回復判斷題**：根據 Log 內容，以 Checkpoint 為基準，判別哪些交易需要 REDO，哪些需要 UNDO。
